# 05 · 海报

## 任务（一句话）

为独立书店「纸页」的年度诗歌节设计一张张贴海报，让 3 米外的人停步、30 厘米处的人读到时间地点。

## 目标用户与场景

- 用户：城市里路过书店/咖啡馆的文艺读者，年龄 20–45，中英文混读。
- 场景：贴在店门与合作咖啡馆橱窗；先被远观吸引，再靠近看活动信息并扫码。
- 前置认知：不一定知道「纸页」，但熟悉诗歌节这类活动的基本信息结构。

## 硬约束

- 载体：印刷海报 A2（594×420mm），CMYK，3mm 出血，图片 ≥300dpi；同时需能在 A4 缩印与社媒方图复用。
- 品牌：书店现有字标与主色；主标题中文，可配英文副题；字体必须有商用授权。
- 合规：不得使用未授权图片/字体；二维码留足静区；日期、地点、票价用占位符，不虚构嘉宾。
- 交付：单面印刷稿 + 3mm 出血标记 + 一份单色/低墨量版本，供预算受限时替换。

## 必须回答的 3 个问题

1. 3 米外第一眼看到什么？它是标题、图形还是颜色，为什么能让人停步？
2. 标题、副题、时间地点、二维码的阅读顺序是什么？靠近后 5 秒内能否找全？
3. 如果只能单色印刷，这张海报还成立吗？哪些元素必须保留、哪些可以删？
