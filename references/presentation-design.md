# 演示文稿与幻灯片版式（Presentation Design）

> 本文件是 design-partner 的第 22 份参考。覆盖：幻灯片尺寸与比例、安全区与边距、字号体系与可读性、文字密度限制、母版与占位符、动画与转场区分、投影对比度、配色策略、图表在幻灯片中的规则、可访问性、远程与线上场景、中文演示场景、反模式清单、自检表、可抄代码。
>
> **核心判断**：演示文稿不是"缩小的文档"，是"放大的瞬间"。每张幻灯片在屏幕上停留 **20–60 秒**，观众在 **3 秒内**决定是否继续看。所有规则围绕一个目标——**3 秒法则**：观众在 3 秒内应抓住这张幻灯片的核心信息。

## 1. 尺寸与比例

### 1.0 速查表

| 比例 | 像素（推荐） | 厘米 | 用途 | 状态 |
|---|---|---|---|---|
| **16:9 宽屏** | **1920×1080** | 33.87×19.05 | 现代投影 / 显示器 / 线上演示 | ✅ 默认首选 |
| 4:3 标准 | 1024×768 | 25.4×19.05 | 旧投影 / 打印讲义 | ⚠️ 仅兼容用 |
| 16:10 | 1920×1200 | — | 部分笔记本原生 | 少见 |
| 1:1 方形 | 1080×1080 | — | 社媒轮播 / Instagram | 特殊场景 |
| 9:16 竖屏 | 1080×1920 | — | 手机全屏 / Stories | 特殊场景 |
| A4 横向 | 1123×794（96dpi） | 29.7×21cm | 打印讲义（横向） | 讲义专用 |
| A4 纵向 | 794×1123（96dpi） | 21×29.7cm | 打印讲义（纵向） | 讲义专用 |

### 1.1 16:9 是事实标准

- **PowerPoint 2013+ 默认 16:9**（13.333×7.5 英寸）
- **Google Slides 默认 16:9**
- **Keynote 默认 16:9**（1280×720 或 1920×1080）
- **reveal.js 默认 16:9**（可配 4:3）

### 1.2 何时用 4:3

| 场景 | 是否用 4:3 | 原因 |
|---|---|---|
| 旧投影仪（XGA 1024×768） | ✅ | 硬件限制 |
| 打印讲义（A4/Letter） | ✅ 横向 | 与纸张比例接近，裁切少 |
| 兼容老系统 | ✅ | 防止黑边 |
| 其他所有场景 | ❌ | 16:9 已是主流 |

### 1.3 混合比例的坑

- **PowerPoint 不支持同一文件内不同比例的幻灯片**——所有幻灯片必须共享同一尺寸
- 如果需要混用：拆成多个文件，用超链接串联
- 切换比例会触发"最大化/确保适配"提示——**选"确保适配"**，否则内容可能超出边界

### 1.4 分辨率与导出

| 导出场景 | 推荐分辨率 | 格式 | 备注 |
|---|---|---|---|
| 投影演示 | 1920×1080 | .pptx | 原生渲染 |
| PDF 分享 | 1920×1080 | .pdf | 矢量保持清晰 |
| 图片导出 | 1920×1080 | .png | 96–150dpi 够用 |
| 高清打印 | 2560×1440+ | .pdf/.png | 300dpi 等效 |
| 社媒分享 | 1080×1080 或 1920×1080 | .png/.mp4 | 按平台定 |

## 2. 安全区与边距

### 2.0 速查表

| 区域 | 16:9 推荐 | 4:3 推荐 | 来源 |
|---|---|---|---|
| **标题安全区**（文字/标题） | **边距 ≥ 5%**（≈96px / 2.54cm） | 边距 ≥ 10% | Adobe After Effects 标题安全区标准：HD 20% inset（保守取一半即可覆盖投影过扫） |
| **动作安全区**（所有内容） | **边距 ≥ 3%**（≈58px / 1.48cm） | 边距 ≥ 5% | Adobe 动作安全区标准：HD 10% inset |
| **投影过扫预留** | 四边各预留 **0.5 英寸（1.27cm）** | 四边各预留 **0.75 英寸** | 不同投影仪裁切量不同 |

### 2.1 为什么需要安全区

| 风险 | 后果 | 安全区防止 |
|---|---|---|
| 投影仪过扫 | 边缘内容被裁切 | 标题安全区 |
| 屏幕比例不匹配 | 黑边或拉伸 | 统一比例 |
| 打印裁切 | 页边内容丢失 | 版心预留 |
| 远程共享缩放 | 边角内容模糊 | 动作安全区 |

### 2.2 边距实操

**PowerPoint 无传统页边距**（不像 Word），用以下方式模拟：

1. **辅助线（Guides）**：视图 → 标尺 + 辅助线，拖到距边缘 5% 处
2. **母版设置**：在 Slide Master 中设好辅助线和占位符位置，全篇继承
3. **文本框内边距**：右键文本框 → 设置形状格式 → 文本框 → 左/右/上/下内部边距（默认 0.1"/0.25"/0.05"/0.25"，建议改为 **0.25"/0.25"/0.1"/0.1"**）

### 2.3 版心推荐值（16:9 / 1920×1080）

| 区域 | 推荐值 | 说明 |
|---|---|---|
| 左右边距 | **96px（2.54cm / 1"）** | 标题安全区 |
| 上边距 | **54px（1.43cm / 0.56"）** | 留标题空间 |
| 下边距 | **54px（1.43cm / 0.56"）** | 留页脚空间 |
| 标题区高度 | **80–120px** | 标题 + 副标题 |
| 正文区高度 | **750–820px** | 1080 − 上下边距 − 标题区 |
| 页脚区高度 | **30–40px** | 页码 / 日期 / logo |
| 列间距 | **24–48px** | 多列布局的 gutter |

## 3. 字号体系与可读性

### 3.0 核心铁律

> **最小字号：24pt（现场演示）/ 18pt（无障碍底线）/ 14pt（仅阅读型讲义）**
> 低于 24pt 的文字在投影上几乎不可读——后排观众看不清，线上观众看小窗更看不清。

### 3.1 字号阶梯（现场演示型）

| 元素 | 字号 | 字重 | 备注 |
|---|---|---|---|
| 主标题（封面） | **44–60pt** | Bold | 第一印象 |
| 章节标题 | **36–44pt** | Semibold | 分节页 |
| 幻灯片标题 | **28–36pt** | Bold | 每页顶部 |
| 副标题 | **24–28pt** | Regular | 标题下补充 |
| 正文/要点 | **24–28pt** | Regular | 项目符号内容 |
| 标注/说明 | **20–22pt** | Regular | 图表标注、注释 |
| 页脚/页码 | **14–16pt** | Regular | 仅参考用 |

### 3.2 字号阶梯（阅读型讲义 / Slidedoc）

> 阅读型演示文稿不是"放大的瞬间"，是"缩小的文档"。字号可以更小，但层次要更清晰。

| 元素 | 字号 | 备注 |
|---|---|---|
| 标题 | 32–40pt | |
| 正文 | 14–20pt | 可接受更小 |
| 脚注 | 12pt | 最小底线 |

### 3.3 字号阶梯（海报型 / 社媒分享）

| 元素 | 字号 | 备注 |
|---|---|---|
| 主标题 | 60–80pt | 远距离可读 |
| 副标题 | 40–50pt | |
| 正文 | 24–30pt | |

### 3.4 字体选择

| 类型 | 推荐字体 | 不推荐 | 原因 |
|---|---|---|---|
| 英文 Sans | **Helvetica / Calibri / Arial / Roboto / Montserrat** | Comic Sans / Papyrus | 屏幕清晰、专业 |
| 英文 Serif | Georgia / Palatino（仅标题） | Times New Roman（过时） | 衬线在屏幕上不如无衬线清晰 |
| 中文 | **思源黑体 / 微软雅黑 / 苹方** | 宋体（正文）、楷体 | 黑体类在投影上笔画清晰 |
| 中文搭配 | 中文黑体 + 英文 Helvetica/Arial | 混用 3+ 种字体 | 一中文 + 一英文 = 最多 2 种 |

### 3.5 字体使用禁忌

- ❌ **禁止 Comic Sans**（"会丧失可信度"）
- ❌ 禁止装饰性、手写体、视觉复杂的字体
- ❌ 禁止全部大写（ALL CAPS）——降低可读性 10–15%
- ❌ 禁止全部加粗——失去强调功能
- ❌ 禁止小型大写字母（small caps）
- ❌ 禁止 Word Art、阴影、描边、文字拉伸
- ❌ 禁止斜体做正文（仅标题或强调）
- ❌ 禁止下划线做强调（仅用于 URL 链接）
- ✅ 如需多种字体：一种 Serif + 一种 Sans-Serif，全程一致

### 3.6 可读性验证方法（Nancy Duarte 法）

> **测量显示器对角线英寸数 → 后退相同数值的英尺数 → 检查是否清晰**

| 屏幕对角线 | 后退距离 | 判断标准 |
|---|---|---|
| 17" | 17 英尺（≈5.2m） | 能看清最小字 |
| 24" | 24 英尺（≈7.3m） | 能看清最小字 |
| 60"（投影） | 60 英尺（≈18m） | 能看清最小字 |

### 3.7 字号一致性规则

- **同一层级文字全篇字号一致**：所有标题同一字号，所有正文同一字号
- **用 Slide Master 设置**，不要逐页手动调
- **单页最多 3 种字号**：标题 + 正文 + 标注
- 字号种类过多 = 视觉混乱

## 4. 文字密度限制

### 4.0 速查表

| 规则名 | 行数 | 每行词数 | 适用场景 | 严格度 |
|---|---|---|---|---|
| **Godin 法则** | — | ≤**6 词/页** | 极简风格演讲 | ★★★★★ |
| **5×5 规则** | ≤5 行 | ≤5 词/行 | 商务演示 | ★★★★ |
| **6×6 规则** | ≤6 行 | ≤6 词/行 | 教学课件 | ★★★ |
| **7×7 规则** | ≤7 行 | ≤7 词/行 | 信息密集型 | ★★ |
| **1-6-6 规则** | 1 个观点/页 | ≤6 条 × ≤6 词 | 专业标准 | ★★★★ |

### 4.1 哪条规则该用

| 场景 | 推荐规则 | 原因 |
|---|---|---|
| 主题演讲 / 发布会 | Godin（≤6 词/页） | 演讲者为主，幻灯片为辅 |
| 商务汇报 / 项目提案 | 5×5 或 1-6-6 | 信息适度，保持专业 |
| 教学课件 / 培训 | 6×6 或 7×7 | 需要信息量，但仍可读 |
| 技术文档型 / Slidedoc | 无限制（但 ≥14pt） | 阅读型，不是演示型 |
| 数据展示 | 少于 5×5，数据为主 | 图表 > 文字 |

### 4.2 中文文字密度

中文字符宽度约为英文单词的 **1/2 到 1/3**，但信息密度更高。调整规则：

| 规则 | 中文版 | 备注 |
|---|---|---|
| 5×5 | ≤5 行 × ≤**10 字**/行 | 中文 10 字 ≈ 英文 5 词 |
| 6×6 | ≤6 行 × ≤**12 字**/行 | |
| Godin | ≤**20 字**/页 | 一句话标题 |

### 4.3 项目符号（Bullet Points）使用纪律

- ✅ **仅用于**：规格说明、流程步骤、并列要点
- ❌ **不应用于**：演讲者大纲、段落缩写、信息堆砌
- Garr Reynolds："**没有任何人能用一张接一张的要点幻灯片做好演示。没有人。**"
- 替代方案：用**视觉化**代替文字列表——图标 + 关键词、流程图、时间线、对比图

### 4.4 一页一信息原则

> **每张幻灯片传达一个核心信息。**

验证方法：用一句话概括这张幻灯片在讲什么——如果需要两句以上，拆成两页。

## 5. 母版与占位符

### 5.0 母版是什么

| 概念 | 定义 | 作用 |
|---|---|---|
| **Slide Master** | 控制所有幻灯片的基础模板 | 统一字体/颜色/位置/logo |
| **Layout（版式）** | Master 下的子模板，定义特定页型 | 标题页/内容页/图片页等 |
| **Placeholder（占位符）** | 预设的虚线框区域，点击即可输入 | 保持全篇对齐一致 |

### 5.1 必备版式清单（6–8 种上限）

| 序号 | 版式名 | 用途 | 占位符 |
|---|---|---|---|
| 1 | 封面 | 标题 + 演讲者 + 日期 | 标题 + 副标题 |
| 2 | 章节分隔 | 大号章节名 | 仅标题 |
| 3 | 标题+正文 | 最常用内容页 | 标题 + 正文（项目符号） |
| 4 | 标题+图片左 | 图文并列 | 标题 + 图片 + 正文 |
| 5 | 标题+图片右 | 图文并列（镜像） | 标题 + 正文 + 图片 |
| 6 | 全图 | 沉浸式视觉 | 仅标题（可选） |
| 7 | 数据/图表 | 图表展示 | 标题 + 图表 + 说明 |
| 8 | 引用/金句 | 大号文字 | 居中文本 |

### 5.2 母版设置步骤（PowerPoint）

1. **视图 → 幻灯片母版**
2. 编辑顶层母版（控制所有子版式）：
   - 设置字体：标题 **36–44pt** / 正文 **18–24pt**
   - 应用品牌色
   - 添加 logo 位置（右下角或左上角，高度 **0.5–1 英寸**）
   - 设置辅助线和占位符位置（对应安全区边距）
3. 创建各版式变体（上表 8 种）
4. **命名每个版式**（如"标题+图片左"，不要用默认的"版式 2"）
5. 关闭母版视图 → 全篇自动应用
6. 保存为模板（.potx）

### 5.3 占位符规则

- ✅ **始终用占位符**而非手动文本框——占位符保证阅读顺序（无障碍）
- ✅ 占位符定义在母版中 → 全篇自动对齐
- ✅ 图片占位符 → 拖入图片自动裁切适配
- ❌ 不要删除占位符后手动画文本框——破坏一致性和无障碍阅读顺序
- ❌ 不要在母版中途修改——已有幻灯片不会自动更新

### 5.4 logo 放置

| 位置 | 推荐场景 | 大小 |
|---|---|---|
| 右下角 | 最常见，不抢注意力 | 高 0.5–1"（1.27–2.54cm） |
| 左上角 | 品牌识别优先 | 高 0.5–1" |
| 不放 | 封面和全图页 | — |
| 全篇一致 | 除封面外每页同位置 | — |

## 6. 动画与转场

### 6.0 定义区分

| 概念 | 定义 | 作用对象 | 量 |
|---|---|---|---|
| **动画（Animation）** | 单个元素的效果 | 幻灯片上的一个元素（文字/形状/图片） | 一页可有多个 |
| **转场（Transition）** | 幻灯片之间的切换效果 | 整张幻灯片 | 每页只能有 1 个 |
| **Morph（变体）** | 看起来像动画的转场效果 | 跨幻灯片的元素位移/缩放 | 属于转场 |

### 6.1 动画四类

| 类型 | 作用 | 何时用 | 何时禁 |
|---|---|---|---|
| **入场（Entrance）** | 元素出现 | 逐条展示要点、引导注意力 | 信息量小时没必要 |
| **退出（Exit）** | 元素消失 | 切换聚焦、腾出空间 | 现场演示几乎不用 |
| **强调（Emphasis）** | 已可见元素的注意力 | 高亮关键数据 | 过度使用令人分心 |
| **动作路径（Motion Path）** | 元素移动 | 演示流程/关系 | 仅限必要场景 |

### 6.2 转场三档

| 档位 | 转场名 | 推荐度 | 场景 |
|---|---|---|---|
| **细微（Subtle）** | Fade（淡入淡出）、Cut（切）、Push（推）、Wipe（擦除）、Morph（变体） | ✅ 推荐 | 专业演示 |
| **适度（Moderate）** | Reveal、Split、Cover、Uncover | ⚠️ 谨慎 | 特定叙事需要 |
| **华丽（Exciting）** | Fall Over、Drape、Curtains、Flash、Flip、Origami、Fracture | ❌ 禁用 | 儿童课件？其他场景全部禁用 |

### 6.3 动画与转场铁律

1. **同一演示文稿全篇统一 1 种转场**——不要每页不同
2. **默认选 Fade**——最安全、最通用
3. **Morph 用于**：元素跨幻灯片平滑移动（如列表重排、数据变化），不是炫技
4. **逐条动画仅用于**：要点需要逐条讲解时（配合演讲节奏）
5. **转场时长 ≤0.5 秒**——超过 0.5 秒观众会等
6. **禁用声音转场**——"嗖""咔"声效会令专业感归零
7. **动画一致性**：要么全篇都有入场动画，要么全篇都没有——混用 = 不统一

### 6.4 何时应完全避免动画

> Lumen Learning / Public Speaking 教材的立场：

- ❌ **应完全避免**：炫酷转场、擦除、淡入淡出（作为装饰）、移动文字、声音及其他各种动画效果
- 原因：这些效果会**分散观众注意力**，将注意力从演讲者和信息转移到屏幕上
- ✅ 例外：动画服务于信息表达（如逐步展示流程步骤、数据柱状图增长动画）

### 6.5 Morph（变体）使用指南

| 场景 | 是否用 Morph | 原因 |
|---|---|---|
| 元素从 A 位置移到 B 位置 | ✅ | 平滑过渡，比硬切更自然 |
| 列表重排序 | ✅ | 视觉上元素交换位置 |
| 数据变化（柱状图增长） | ✅ | 比重新画一张更流畅 |
| 纯装饰效果 | ❌ | 令人晕眩（有人报告"像在船上"） |
| 频繁使用（每页都用） | ❌ | 审美疲劳 |

## 7. 投影对比度与配色

### 7.0 对比度阈值

| 文本类型 | 对比度要求 | 来源 |
|---|---|---|
| 正文（<18pt） | **≥ 4.5:1** | WCAG 2.1 AA SC 1.4.3 |
| 大文本（≥18pt / ≥14pt bold） | **≥ 3:1** | WCAG 2.1 AA SC 1.4.3 |
| 非文本图形元素 | **≥ 3:1** | WCAG 2.2 SC 1.4.11 |

### 7.1 投影 vs 屏幕的差异

| 因素 | 屏幕 | 投影 | 调整 |
|---|---|---|---|
| 对比度损失 | 无 | **降 20–40%** | 设计时对比度比目标高 50% |
| 环境光影响 | 可控 | 强（会议室灯光） | 避免暗色背景 + 低对比度 |
| 色彩偏差 | 准确 | 偏色（取决于灯泡） | 避免精细色差 |
| 观看距离 | 30–60cm | 3–15m | 字号需更大 |

### 7.2 安全配色策略

| 策略 | 推荐值 | 说明 |
|---|---|---|
| 深底浅字 | 深蓝/深灰底 + 白/浅灰字 | 投影友好，减少环境光反射 |
| 浅底深字 | 白/浅灰底 + 黑/深灰字 | 最安全，对比度最高 |
| 品牌色使用 | 品牌色仅用于标题/强调/CTA | 不要做正文背景 |
| 背景色一致 | **全篇背景色一致** | 不要每页换背景色 |

### 7.3 禁止的配色

| 组合 | 原因 |
|---|---|
| 红 + 绿 | 红绿色盲（最常见，影响 ~8% 男性） |
| 红 + 蓝（某些组合） | 产生**视觉振动**，令人不适 |
| 亮色背景（黄/粉/橙） | 过于分散注意力 |
| 纯黑 + 纯白（长时间） | 对比度过高，长时间观看眼疲劳 |

### 7.4 投影对比度自检

```bash
# 使用 WebAIM 对比度检查器
# https://webaim.org/resources/contrastchecker/

# 或用对比度公式自行计算：
# contrast = (L1 + 0.05) / (L2 + 0.05)
# L1 = 较亮颜色的相对亮度, L2 = 较暗颜色的相对亮度
# 正文 ≥ 4.5, 大字 ≥ 3.0
```

## 8. 图表在幻灯片中的规则

### 8.0 核心原则

> **一张幻灯片一个图表。两个图表 = 拆两页。**

### 8.1 图表字号

| 元素 | 最小字号 | 推荐 |
|---|---|---|
| 图表标题 | 24pt | 与幻灯片标题一致 |
| 坐标轴标签 | 18pt | 投影可读 |
| 数据标注 | 18pt | 关键数值必须大 |
| 图例 | 16pt | 最小底线 |
| 脚注 | 14pt | 仅参考 |

### 8.2 图表在幻灯片中的尺寸

| 场景 | 图表占比 | 留白 |
|---|---|---|
| 数据为主的页 | **60–70%** 幻灯片面积 | 30–40% 留白 |
| 图文并列 | **40–50%** | 50–60% 给文字 |
| 全图数据页 | **80%+** | 仅留标题和说明 |

### 8.3 图表颜色

- 使用 **3–4 种区分色**（色盲安全）
- 推荐色板：Okabe–Ito 8 色（见 `accessibility.md`）
- 避免用红绿区分数据系列
- 详细规则见 `dataviz.md`

## 9. 可访问性

### 9.0 WCAG 对演示文稿的要求

| SC 编号 | 要求 | 级别 | 对演示的影响 |
|---|---|---|---|
| **1.4.3** | 文字对比度 ≥4.5:1（正文）/ ≥3:1（大字） | AA | 配色必须验证 |
| **1.4.1** | 不能仅靠颜色传递信息 | A | 状态用图标+颜色双重编码 |
| **1.4.5** | 文字图片（避免用图片代替文字） | AA | 用文本不用截图 |
| **2.3.1** | 闪烁 ≤3 次/秒 | A | 禁止快速闪烁动画 |
| **2.2.2** | 自动播放/滚动 >5s 需可暂停 | A | 自动动画需可控 |
| **1.1.1** | 所有图片有 alt 文本 | A | 右键 → 编辑替代文本 |
| **1.3.1** | 信息与关系可编程确定 | A | 用占位符不用手动文本框 |
| **2.4.3** | 焦点顺序有意义 | A | 阅读顺序 = 占位符顺序 |

### 9.1 可访问性实操清单

1. **用内置版式**（不用手动文本框）→ 保证阅读顺序
2. **所有图片加 alt 文本**：右键 → 编辑替代文本 → 简洁描述
3. **装饰性图片标记为装饰性**（screen reader 跳过）
4. **对比度 ≥4.5:1**：用 Color Contrast Analyzer 验证
5. **描述性超链接**：不贴裸 URL，不用"点击这里"
6. **无障碍字体**：Sans-serif（Arial / Calibri / Verdana），最小 **18pt**
7. **视频加字幕**：PowerPoint → 插入 → 字幕
8. **表格表头行**：选中表格 → 表格设计 → 勾选"标题行"
9. **复杂图表加文字说明**：speaker notes 或幻灯片内文字摘要
10. **运行 Accessibility Checker**：审阅 → 检查无障碍 → 修所有错误

### 9.2 闪烁与光敏性

| 规则 | 阈值 | 来源 |
|---|---|---|
| 闪烁频率 | ≤**3 次/秒** | WCAG 2.3.1（Level A，不可豁免） |
| 闪烁面积 | ≤**25%** 屏幕面积（10°视角内） | WCAG 2.3.1 |
| 亮度变化 | <**10%** 最大相对亮度 | general flash 定义 |
| 饱和红闪烁 | ❌ 完全禁止 | red flash 定义 |

## 11. 中文演示场景

### 11.0 中文字号调整

| 因素 | 英文 | 中文 | 调整 |
|---|---|---|---|
| 最小正文字号 | 24pt | **26–28pt** | 中文笔画密度高，同字号视觉更小 |
| 标题字号 | 28–36pt | **32–40pt** | 同上 |
| 行距 | 1.2–1.4 | **1.4–1.6** | 中文需更大行距避免拥挤 |
| 字间距 | 默认 | 适当加宽 | 标题可加 1–2 磅字间距 |

### 11.1 中文字体推荐

| 场景 | 推荐字体 | 不推荐 |
|---|---|---|
| 正文 | **思源黑体 / 微软雅黑 / 苹方** | 宋体（投影上笔画太细） |
| 标题 | **思源黑体 Bold / 微软雅黑 Bold** | 楷体、隶书 |
| 中英混排 | 中文黑体 + 英文 Helvetica/Arial | 混用衬线和无衬线 |

### 11.2 中文标点与排版

- 全角标点（，。、；：""''）
- 中英文之间加**半角空格**
- 数字与中文之间加**半角空格**
- 数字用半角（1234），不用全角（１２３４）
- 标题和按钮文字**不加句号**

### 11.3 中文演示密度

| 场景 | 每页字数上限 | 项目符号 |
|---|---|---|
| 发布会/演讲 | ≤**20 字** | 不用 |
| 商务汇报 | ≤**50 字** | ≤5 行 × ≤10 字 |
| 教学课件 | ≤**70 字** | ≤6 行 × ≤12 字 |
| 技术文档型 | 无限制 | 可多行 |

## 12. 版式构图法则

### 12.1 三分法则

- 用 **2 条水平 + 2 条垂直**假想线将幻灯片分为 **9 个区域**
- 最具视觉吸引力的位置在**线条交叉点**
- ✅ 将文字和图片对齐到交叉点
- ❌ 避免所有内容居中放置（除非是封面/引用页）

### 12.2 Z 模式阅读

- 在从左到右的语言环境中：
- 观众视线从**左上角**开始 → 沿 **Z 形**扫视 → 从**右下角**离开
- 布局策略：
  - 左上角：**最重要的信息**（标题/logo）
  - 右上角：**次要信息**（副标题/导航）
  - 左下角：**支撑信息**（图表/图片）
  - 右下角：**行动召唤**（CTA/联系方式）

### 12.3 留白规则

- **留白 = 呼吸空间** → 吸引注意力到焦点
- 留白让幻灯片显得**更优雅、更专业**
- ❌ 不要用文字和图片**过度拥挤**幻灯片
- 推荐留白占比：**30–50%** 幻灯片面积

### 12.4 视觉引导

- 所有人物和动物的朝向应**面向幻灯片内部**，最好朝向主焦点
- 图片运动方向（汽车、箭头、视线）应**面向内部**
- ❌ 视线或运动方向**指向幻灯片外部** → 观众也会看向那里

### 12.5 一致性规则

- 全篇重复使用：相同**颜色、字体、图片风格、布局**
- 讲义也应匹配**相同的格式**
- 团队协作时尤其重要

## 13. 演示节奏与信息流

### 13.0 切换节奏

| 演示类型 | 每页停留时间 | 总页数（20 分钟） | 信息密度 |
|---|---|---|---|
| 主题演讲 | 15–30 秒 | 40–80 页 | 极低（视觉为主） |
| 商务汇报 | 30–60 秒 | 20–40 页 | 中 |
| 教学课件 | 60–120 秒 | 10–20 页 | 中高 |
| 技术分享 | 45–90 秒 | 15–25 页 | 中 |

### 13.1 演讲-幻灯片节奏

> Mayer (2001) 研究表明：**分裂注意力**影响信息保留能力。

正确流程：

1. **演讲** → 切换幻灯片
2. **等待观众阅读**（2–3 秒）
3. **恢复演讲**

错误流程：

1. 切换幻灯片 + 同时开始讲解（观众在"读"还是"听"之间犹豫）

### 13.2 引用语规则

- ✅ 可以使用，但需满足：**简短、清晰、少量使用**
- ✅ 出现时**立即停止演讲**，大声朗读或给观众**默读时间**
- ✅ 替代方案：演讲者/主题的照片 + 引用中的关键短语

### 13.3 信息结构（倒金字塔）

| 位置 | 内容 | 观众关注度 |
|---|---|---|
| **前 3 秒** | 标题 / 核心结论 / 关键数据 | ★★★★★ 最高 |
| 3–10 秒 | 支撑要点 / 图表 | ★★★ 中等 |
| 10 秒后 | 详细数据 / 脚注 | ★ 最低 |

## 16. 20 条反模式

| # | 反模式 | 后果 | 正确做法 |
|---|---|---|---|
| 1 | 字号 <24pt | 后排/线上看不清 | 最小 24pt，线上 28pt |
| 2 | 一页超过 7 行文字 | 信息过载 | 5×5 或 1-6-6 规则 |
| 3 | 全篇都用项目符号 | 枯燥乏味 | 用视觉化替代文字列表 |

```vba
Sub CheckMinFontSize()

    minSize = 24  ' 现场演示最小 24pt
    
    Dim slide As slide
    Dim shp As Shape
    Dim txtRange As TextRange
    Dim i As Integer
    Dim violations As String

                If shp.TextFrame.HasText Then

                            violations = violations & "Slide " & slide.SlideIndex & _
                                " Shape " & shp.Name & _
                                " FontSize " & txtRange.Runs(i).Font.Size & vbCrLf
                        End If
                    Next i
                End If
            End If
        Next shp
    Next slide
    
    If violations = "" Then
        MsgBox "All fonts ≥ " & minSize & "pt ✅", vbInformation
    Else
        MsgBox "Violations:" & vbCrLf & violations, vbExclamation
    End If
```

### 18.3 对比度检查（Python）

```python
"""演示文稿配色对比度检查器
使用 WCAG 相对亮度公式验证文字与背景对比度
"""
import re

def hex_to_rgb(hex_color: str) -> tuple:
    """#RRGGBB → (r, g, b)"""
    hex_color = hex_color.lstrip('#')
    return tuple(int(hex_color[i:i+2], 16) for i in (0, 2, 4))

def relative_luminance(r: int, g: int, b: int) -> float:
    """WCAG 相对亮度公式"""
    def channel(c):
        c = c / 255.0
        return c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4
    return 0.2126 * channel(r) + 0.7152 * channel(g) + 0.0722 * channel(b)

def contrast_ratio(fg: str, bg: str) -> float:
    """计算前景/背景对比度"""
    fg_rgb = hex_to_rgb(fg)
    bg_rgb = hex_to_rgb(bg)
    l1 = relative_luminance(*fg_rgb)
    l2 = relative_luminance(*bg_rgb)
    lighter = max(l1, l2)
    darker = min(l1, l2)
    return (lighter + 0.05) / (darker + 0.05)

def check_presentation_colors(fg: str, bg: str, context: str = "body"):
    """检查配色是否达标"""
    ratio = contrast_ratio(fg, bg)
    if context == "body":
        threshold = 4.5
        label = "正文 (≥4.5:1)"
    elif context == "large":
        threshold = 3.0
        label = "大字 (≥3.0:1)"
    else:
        threshold = 3.0
        label = "图形 (≥3.0:1)"
    
    status = "✅ PASS" if ratio >= threshold else "❌ FAIL"
    print(f"{label}: {fg} on {bg} = {ratio:.2f}:1 {status}")
    return ratio >= threshold

# 用法示例
if __name__ == "__main__":
    # 白字 on 深蓝底
    check_presentation_colors("#FFFFFF", "#1A1A2E", "body")
    # 浅灰字 on 白底
    check_presentation_colors("#888888", "#FFFFFF", "body")
    # 大标题
    check_presentation_colors("#FF6B6B", "#FFFFFF", "large")
```

### 18.6 Python-pptx 生成幻灯片模板

```python
"""用 python-pptx 创建符合规范的幻灯片模板"""
from pptx import Presentation
from pptx.util import Inches, Pt, Emu
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN

def create_template():
    prs = Presentation()
    
    # 16:9 尺寸（13.333 × 7.5 英寸）
    prs.slide_width = Inches(13.333)
    prs.slide_height = Inches(7.5)
    
    # 获取母版
    slide_layout = prs.slide_layouts[6]  # 空白版式
    
    # --- 封面 ---
    slide = prs.slides.add_slide(slide_layout)
    title = slide.shapes.add_textbox(
        Inches(1), Inches(2.5), Inches(11.333), Inches(1.5)
    )
    tf = title.text_frame
    tf.text = "演示标题"
    tf.paragraphs[0].font.size = Pt(44)
    tf.paragraphs[0].font.bold = True
    tf.paragraphs[0].font.color.rgb = RGBColor(0x1A, 0x1A, 0x2E)
    
    subtitle = slide.shapes.add_textbox(
        Inches(1), Inches(4), Inches(11.333), Inches(0.8)
    )
    subtitle.text_frame.text = "副标题 / 演讲者 / 日期"
    subtitle.text_frame.paragraphs[0].font.size = Pt(24)
    subtitle.text_frame.paragraphs[0].font.color.rgb = RGBColor(0x66, 0x66, 0x66)
    
    # --- 内容页 ---
    slide2 = prs.slides.add_slide(slide_layout)
    
    # 标题（安全区内）
    title2 = slide2.shapes.add_textbox(
        Inches(0.67), Inches(0.4),  # 5% 安全区
        Inches(12), Inches(0.8)
    )
    title2.text_frame.text = "内容页标题"
    title2.text_frame.paragraphs[0].font.size = Pt(32)
    title2.text_frame.paragraphs[0].font.bold = True
    
    # 正文
    body = slide2.shapes.add_textbox(
        Inches(0.67), Inches(1.5),
        Inches(12), Inches(5.5)
    )
    body.text_frame.text = "• 要点一\n• 要点二\n• 要点三"
    for para in body.text_frame.paragraphs:
        para.font.size = Pt(24)
        para.font.color.rgb = RGBColor(0x33, 0x33, 0x33)
    
    # 页脚
    footer = slide2.shapes.add_textbox(
        Inches(0.67), Inches(6.8),
        Inches(12), Inches(0.4)
    )
    footer.text_frame.text = "页码 / 日期 / logo"
    footer.text_frame.paragraphs[0].font.size = Pt(14)
    footer.text_frame.paragraphs[0].font.color.rgb = RGBColor(0x99, 0x99, 0x99)
    
    prs.save('presentation_template.pptx')
    print("Template created ✅")

if __name__ == "__main__":
    create_template()
```
