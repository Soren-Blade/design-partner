## 用法
- **Design & Canvas**：设计画布与原型
- **Development**：前端/开发工具
- **Capture & Media**：截图、录屏、媒体处理
- **Productivity & Desktop**：效率与桌面工具

## Design & Canvas (2)

- **[Figma](https://figma.com/)**（免费+付费） — Collaborative interface design and prototyping platform.
- **[Framer](https://framer.com/)** — Visual canvas designing and publishing websites.

## Development (3)

- **[Cursor](https://cursor.com/)**（免费+付费） — AI-first code editor for rapid development.
- **[Zed](https://zed.dev/)**（免费） — High-performance code editor built for low latency.
- **[Playwright](https://playwright.dev/)** — Reliable browser automation and end-to-end testing.

## Capture & Media (1)

- **[Squoosh](https://squoosh.app/)** — Browser image compression with visual comparisons.
