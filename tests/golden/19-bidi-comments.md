# 19 · 国际化双向文本

## 任务（一句话）

设计一个支持中 / 英 / 阿语的「评论列表」：每条含用户名、评论正文、时间、点赞数；用户可用任意语言输入，同一页面会同时出现从左到右与从右到左的内容。

## 目标用户与场景

- 用户：中东与东亚市场的社区用户；在同一条讨论里混用阿拉伯语、英语与中文。
- 场景：快速扫评论，点用户名进主页，复制其中的链接或邮箱；RTL 界面里也会读到英文品牌名与数字。
- 前置认知：对自己语言的阅读方向极其敏感；一个标点跑到句首就会被读成「另一个意思」。

## 硬约束

- 载体：Web，桌面与手机；`<html lang>` 随 locale；支持 200% 缩放不横向滚动。
- 品牌：RTL 下布局镜像，但品牌 logo 不镜像；媒体播放控件不镜像。
- 合规：URL、邮箱、@用户名、数字不得被重排；方向变化不得只靠 CSS `direction`；读屏语言切换正确。
- 交付：LTR / RTL 两版 + 混合方向评论示例 + 图标镜像清单。

## 必须回答的 3 个问题

1. 页面 base direction 与单条评论方向如何分工，方向信息由哪一层声明？
2. 用户名、URL、邮箱、数字在不同方向的句子里如何隔离，哪些位置不能用标记？
3. 哪些图标镜像、哪些不镜像，判据是什么？
