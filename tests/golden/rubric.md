# 评分 Rubric（五轴 0–3 分）

评分前先完成盲评去标识（见文末流程）。每轴独立打分，不允许「总分印象」倒推各轴。
所有分数必须附一句可核对的证据（哪个元素、哪条约束）。

## 五轴锚点

### 1. 层级清晰（Hierarchy）

读者能否在 3 秒内说出「先看什么、再看什么、可以忽略什么」。

| 分 | 锚点 |
|---|---|
| 0 | 主次不分：所有元素同一视觉重量，或主信息被装饰/导航淹没。 |
| 1 | 有主标题但层级断裂：二级信息比一级更抢眼，或分组靠猜。 |
| 2 | 主次可辨，三级以内层级完整；存在 1–2 处次要元素抢注意力。 |
| 3 | 3 秒内可复述页面目的与行动；层级与任务顺序一致，删掉任何一层都会损失信息。 |

### 2. 节奏（Rhythm）

间距、字号、密度是否形成可预期的呼吸，而不是均匀铺开或随机跳动。

| 分 | 锚点 |
|---|---|
| 0 | 间距随手写（13/17/22px 混用），密度均匀到没有重点，或拥挤到无法扫描。 |
| 1 | 有分组但节奏单一：所有区块同样间距，长页面读起来平。 |
| 2 | 间距成阶梯、分组明确；个别区块（如表格/表单）节奏与全局不协调。 |
| 3 | 疏密有意图：重点区留白、密集区可扫描；跨区块节奏一致且服务于任务。 |

### 3. 一致性（Consistency）

同一产物内部的颜色、字号、圆角、间距、文案语气是否同源。

| 分 | 锚点 |
|---|---|
| 0 | 明显多套体系拼贴：同类元素多种样式，或文案语气前后冲突。 |
| 1 | 主色/主字号统一，但次级元素（标签、图标、错误态）各写各的。 |
| 2 | token 基本统一；存在少量一次性数值或未覆盖的状态样式。 |
| 3 | 全部关键样式可回溯到一套 token/规则；状态、空态、错误态同语气。 |

### 4. 记忆点（Memorability）

产物是否有「可被复述的一个决定」，而不是安全但无辨识度的模板。

| 分 | 锚点 |
|---|---|
| 0 | 完全模板化，换成任何品牌都成立；没有任何设计决策。 |
| 1 | 有一处装饰性差异（插画/渐变），但与任务无关，删掉不影响理解。 |
| 2 | 有一个与内容绑定的设计决定（结构、隐喻或排版），能被记住。 |
| 3 | 记忆点同时承担信息功能：复述它就说清了产品价值，且不损害可用性。 |

### 5. 风险（Risk，3 = 风险最低）

可访问性、合规、误导、实现可行性上的硬伤。**分数越高越安全**，不要与「大胆」混淆。

| 分 | 锚点 |
|---|---|
| 0 | 存在阻断性硬伤：对比度不达标且承载信息、键盘不可达、虚假/违法文案、暗黑模式（默认勾选、假关闭等）。 |
| 1 | 多处风险未处理：焦点态缺失、错误只靠颜色、移动端溢出、法务/隐私表述无依据。 |
| 2 | 主要风险已规避；仍有 1–2 处需在交付说明中标注的边界（如极端文案长度、RTL）。 |
| 3 | 风险清单逐条有对策或明确标注；WCAG 2.2 AA 关键项、合规表述、降级路径都可核对。 |

## 强制裁决记录模板

盲评出现**任一轴分歧 >1 分**，或两案总分差 ≤2 分时，必须填写并留档：

```
### 裁决记录 · <brief 编号> · <日期>
- 评审：R1 / R2（+ 裁决人，如有）
- 方案：A = <来源，去标识后代号>；B = <来源>
- 分歧轴与分数：R1 节奏 1 / R2 节奏 3
- 双方证据：R1「…」；R2「…」
- 核对动作：<重看截图/走查键盘/量对比度/复读文案>
- 裁决：<最终分>，理由：<为什么一方证据更强>
- 是否回改 brief：<否 / 是，原因>
```

规则：

- 分歧 = 1 分：取两人平均并保留证据，不强制裁决。
- 分歧 >1 分：先各自补充证据，再复核；仍不一致则由第三人裁决，理由入档。
- 禁止用「整体感觉更好」作为裁决理由；必须指向 rubric 锚点。

## 盲评流程

1. **去品牌**：移除 logo、品牌名、真实客户名、域名、作者署名；文案中的品牌词替换为
   `[品牌]`；文件名改为 `case-A` / `case-B`，顺序随机。
2. **同材料**：两案使用相同 brief、相同素材、相同输出尺寸；截图/导出在相同缩放下生成。
3. **≥2 评审**：至少两人独立打分，互不看对方分数；评审不得是产出者本人。
4. **先证据后分数**：每轴先写一句证据，再落 0–3；不允许只写分数。
5. **分歧处理**：按上面的强制裁决模板执行；>1 分必须写理由并留档。
6. **记录**：结果写入 `baseline.md`（含日期、版本、两案来源、逐轴分数、裁决记录）。
7. **不预填**：brief 中的评分栏在盲评前必须为空。
