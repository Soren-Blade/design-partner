# 版式与网格（Editorial Layout）

> 快照 2026-11-01 · 适用：海报 / 长图 / 社媒图 / 印刷品 / 长文页面 / 作品集版式
> 本文件解决一件事：**把"排版好看"拆成可执行的数值与判断顺序**。凡是能给出数字的地方都给数字；凡是行业惯例而非标准的，明确标注「惯例」。

**取源**（全部读原文，不引二手总结）
- Jan Tschichold《The Form of the Book》/ Van de Graaf canon：页边距 2:3:4:6（[Canons of page construction](https://en.wikipedia.org/wiki/Canons_of_page_construction)）
- Butterick's Practical Typography：[line-length](https://practicaltypography.com/line-length.html) / [line-spacing](https://practicaltypography.com/line-spacing.html) / [page-margins](https://practicaltypography.com/page-margins.html)
- ISO 216 纸张尺寸（A/B 系列，√2:1，向下取整规则，公差 ±1.5/2/3mm）
- 印刷出血：[Bleed (printing)](https://en.wikipedia.org/wiki/Bleed_(printing))（英制 1/8″、公制 2–5mm、大幅面 +0.25″、模切 1/4″）
- 平台官方：Instagram 图片分辨率帮助页、X Ads creative specs、YouTube 帮助中心
- W3C [clreq 中文排版需求](https://www.w3.org/TR/clreq/)（汉字 1:1、破折号 2em、中西混排 ≤1/4 字宽、纵中横排）
- MDN：`text-wrap`（balance 行数上限）、`initial-letter`、`hanging-punctuation`、`subgrid`、`orphans`
- 仓库 star/许可：GitHub API 实测（2026-11-01，见 §16）

## §0 一页速查（赶时间只看这里）

| 问题 | 直接答案 |
|---|---|
| 页边距怎么给 | 内:上:外:下 = **2:3:4:6**（Van de Graaf，页面 2:3 时）；下边距比上边距大 **0.25″(6mm)** 才不"下垂" |
| 行长多少 | 西文 **45–90 字符**（2–3 个字母表）；中文 **25–40 字/行**（移动端 15–20） |
| 行距多少 | 西文 **120–145%** 字号；中文 **1.6–1.8** |
| 字号阶梯 | 比例 **1.2（稳）/1.25（常用）/1.333（编辑感）/1.5（海报）**，正文:标题落差 **2–4 倍** |
| 栏数多少 | **12 栏**（能被 2/3/4/6 整除）；内容型 6 栏够用；海报 3–6 栏 |
| gutter 多少 | 正文栏间 **16–24px**（印刷 4–5mm）；栏越窄 gutter 越大 |
| 基线网格 | **4 或 8px**（印刷 12pt 基线 = 14.4pt 行距）；所有行高必须是基线的整数倍 |
| 海报出血 | **3mm**（欧）/ **1/8″=3.18mm**（美）；大幅面 **+6.35mm**；安全区再内缩 **3–5mm** |
| 印刷分辨率 | 成品尺寸下 **300ppi**；A1 以上可降 **150ppi** |
| 长图宽度 | 微信 **750**、通用/小红书 **1080**、公众号次条 **1080×1440**；正文 ≥ **44px**（1080 宽时） |
| 社媒主尺寸 | IG **1080 宽 / 1.91:1–3:4**；X 广告 **1.91:1=800×418**；微信封面 **900×383**；YT 缩略图 **1280×720** |
| 留白比例 | 编辑页 **30–45%**、海报 **40–60%**、信息长图 **20–30%** |
| 一段话最多几行 | 手机 **≤5 行**、桌面 **≤7 行**；超过就拆段或加小标题 |

## §1 先判载体：五类产出的本质差异

版式不是一套规则通吃。**先定载体，再定网格**，顺序反了会做出"网页排版的海报"。

| 载体 | 观看距离 | 阅读方式 | 信息上限 | 版式的首要任务 | 最常见的错 |
|---|---|---|---|---|---|
| **海报** | 1–5m（远） | 3 秒扫读，无交互 | 1 个主张 + ≤3 条支撑 | **远距离识别**：字号、对比、图形 | 把正文级信息塞满，远处一片灰 |
| **长图 / 信息图** | 30–50cm | 连续下滑，单列 | 5–9 个信息点 | **节奏**：每屏一个点，屏与屏有钩子 | 一屏塞 4 个点，用户在第 2 屏划走 |
| **社媒图** | 30cm，缩略图 100px | 0.5 秒决定点不点 | 1 句话 + 1 个视觉 | **缩略图可读性**：大字、少字、高对比 | 按 1080 全尺寸设计，缩到 120px 全糊 |
| **印刷品** | 30cm | 翻页/摊开 | 按开本定 | **物理约束**：出血、装订、纸白、色域 | 忘了内侧装订边，字进订口 |
| **长文网页** | 50–70cm | 滚动 | 按章节 | **行长与节奏**：栏宽、小标题、图注 | 通栏 1400px 正文，一行 100+ 字 |

**判断口诀**：**距离决定字号，时长决定信息量，媒介决定安全区**。三者定完，网格才有意义。

## §2 网格类型与选择

| 类型 | 结构 | 适合 | 不适合 |
|---|---|---|---|
| **单栏（manuscript）** | 一个版心，无分栏 | 长文、书、博客正文、公文 | 多图混排、杂志页 |
| **多栏（column）** | 2–4 等宽栏 + gutter | 杂志内页、报纸、长图分栏 | 移动端（一屏一栏） |
| **模块网格（modular）** | 栏 × 行 = 模块矩阵 | 卡片墙、产品目录、仪表盘 | 连续长文（模块会切断阅读） |
| **基线网格（baseline）** | 只锁垂直节奏（水平线阵列） | 任何多栏混排的底层 | 单独使用（不解决水平对齐） |
| **层级网格（hierarchical）** | 按内容重要性自由分区，仅共享边距 | 海报、落地页首屏、编辑型专题 | 需要严格对齐的表格化内容 |

**选择顺序**（照做即可）：
1. 内容是否连续成段？→ 是：单栏/多栏 + **基线网格**。
2. 内容是否等权、可比较？→ 是：**模块网格**。
3. 是否有明确的主次（一个主角）？→ 是：**层级网格**，但**边距与基线必须继承**。
4. 移动端一律退回**单栏**，网格只保留"边距 + 基线"两件事。

**关键纪律**：**层级网格不是"不要网格"**。海报可以打破栏线，但不能打破边距和基线——打破的是"格"，保留的是"律"。

## §3 栏数、gutter 与基线网格

### 3.1 为什么是 12 栏

12 的约数有 2、3、4、6——**同一套栏线可以切出 1/2、1/3、1/4、1/6 的所有组合**，这是它成为默认值的唯一原因（数学，不是审美）。

| 栏数 | 可切分 | 典型用途 |
|---|---|---|
| 4 | 1/2、1/4 | 简单落地页、移动端平板 |
| 6 | 1/2、1/3、1/6 | 内容型站点、博客列表 |
| **12** | 1/2、1/3、1/4、1/6 | **默认**：营销页、后台、杂志 |
| 16 | 1/2、1/4、1/8、1/16 | 大屏、复杂专题 |
| 24 | 细分 | Ant Design 体系（24 栅格） |

Müller-Brockmann《Grid systems in graphic design》中的示例以 **8 / 12 / 16 / 20 / 32** 栏为主（书籍示例，非标准）。**栏数不是越多越好**：栏数 × 2 > 屏上元素数时，网格就只是装饰。

### 3.2 gutter 与栏宽的关系

- **gutter 固定、栏宽流体**（与响应式一致）：gutter 用百分比会导致大屏松、小屏挤。
- 经验值：**gutter ≈ 栏宽的 1/4 ~ 1/3**。栏越窄，gutter 相对越大，否则两栏文字会"粘"在一起。
- 具体：桌面正文栏间 **16–24px**；印刷 **4–5mm**（约 11–14pt）；卡片网格 **16/24/32px**（8 倍数）。

### 3.3 基线网格（最容易被跳过、收益最大的一项）

**规则**：所有垂直尺寸（行高、段间距、图高、卡片高、模块间距）都是同一个基线单位的**整数倍**。

- 网页基线 **4px 或 8px**（与 8pt 间距系统同源）。正文行高必须落在基线上：16px 字号 × 1.5 = 24px = 3×8 ✓；× 1.6 = 25.6px ✗ → 取 **24px 或 32px**。
- 印刷基线常见 **12pt 字 / 14.4pt 行距**（1.2 倍）；中文书常见 **9pt 字 / 15pt 行距**（1.67）。
- 图片高度也要对齐基线：`height: calc(8px * N)`，否则图下方的文字会"跳"。

**检验方法**：把整页压暗到只剩文字块，若每一行文字的基线能连成等距横线 → 过；出现半行错位 → 有元素没对齐基线。

## §4 版心与页边距（版心宽度 / 页边距比例）

### 4.0 版心宽度速查（一句话答案）

| 载体 | 版心宽度 | 换算 |
|---|---|---|
| 书页 / 印刷品 | 页宽 × **0.55–0.70** | A4 → 116–148mm |
| 网页长文 | **680–760px**（中文 38em） | ≈ 25–40 字/行 |
| 营销页 / 官网 | **1140–1280px** | 与 Bootstrap 版心阶梯对齐 |
| 表单 / 设置页 | **≤640px** | 单列，字段不再分栏 |
| 中后台内容区 | **不限宽**，但最小 **≥720px** | 侧栏 208/64px 之外 |
| 海报 | 短边 × **0.70–0.85** | A2 → 294–357mm |

**版心先定，边距是结果**——不要先给 margin 再算内容宽度，会得到 6.5″ 这种"打字机行长"。

### 4.1 Van de Graaf canon（唯一有几何证明的边距系统）

对任意页面比例都成立，2:3 页面时结果最漂亮：

| 边距 | 值（页面尺寸的比例） |
|---|---|
| 内侧 | **1/9** 页宽 |
| 外侧 | **2/9** 页宽 |
| 上 | **1/9** 页高 |
| 下 | **2/9** 页高 |

→ 内 : 上 : 外 : 下 = **2 : 3 : 4 : 6**（页面 2:3 时）；一般式 **1 : R : 2 : 2R**（页面 1:R）。
→ 两个漂亮性质：**版心与页面同比例**；**版心高 = 页面宽**。

**注意**：这是"书页"系统，内侧窄是因为要装订。**网页/海报不要照抄 1/9、2/9 的比例**——网页没有装订，均匀边距或"下大于上"更合适。**借它的方法，不借它的数字。**

### 4.2 实用边距表

| 场景 | 左右边距 | 上下边距 | 备注 |
|---|---|---|---|
| A4 长文（12pt 西文） | **1.5–2.0″（38–51mm）** | 同上 | Butterick：1″ 太小，是打字机遗留 |
| A4 中文公文 | 上 37mm / 下 35mm / 左 28mm / 右 26mm | — | GB/T 9704 惯例，按单位模板走 |
| 网页长文 | 版心 **680–760px**（中文 38em） | 段落间距 ≥ 行高 | 行长优先于边距 |
| 海报 A2 | 短边 **5–8%** | 同上 | 出血另加，不占边距 |
| 社媒图 | 短边 **5–7%** | 同上 | 平台会裁边，安全区见 §12 |
| 名片/小件 | **3–4mm** | 同上 | 小于 3mm 裁切必偏 |

**两条硬规则**：
1. **下边距 ≥ 上边距**，差值约 **6mm（0.25″）**。等分会让文字块看起来往下坠（视觉重心在几何中心之上）。
2. **非对称必须明显**：左右边距想做不对称，差值 ≥ **25mm（1″）**，否则看起来像"没对齐"而不是"故意不对称"。

### 4.3 版心宽度与开本

- 版心宽 ≈ **页宽 × 0.55–0.70**（书页）；低于 0.5 显空，高于 0.75 显挤。
- 双页跨页（spread）设计时，**内两栏要合并考虑**：把两页当一张大页面排版，再从中缝切开——这是杂志跨页图的正确做法，反过来做必错位。

## §5 字号模数与层级（字号阶梯）

### 5.1 模数比例（modular scale）

以正文为基准（1.0），乘同一个比例得到各级字号：

| 比例 | 名称 | 16px 基准下的阶梯 | 气质 |
|---|---|---|---|
| 1.125 | 音乐 2 度 | 16 / 18 / 20.3 / 22.8 | 极稳，层级弱，适合长文 |
| **1.2** | 小三度 | 16 / 19.2 / 23 / 27.6 | **通用默认**，落差刚好 |
| **1.25** | 大三度 | 16 / 20 / 25 / 31.3 | UI/后台常用，识别快 |
| 1.333 | 纯四度 | 16 / 21.3 / 28.4 / 37.9 | 编辑感强，杂志/专题 |
| 1.414 | √2 | 16 / 22.6 / 32 / 45.3 | 海报、A 系列纸张同源 |
| 1.5 | 纯五度 | 16 / 24 / 36 / 54 | 强对比，适合远看 |
| 1.618 | 黄金比 | 16 / 25.9 / 41.9 / 67.8 | 大标题震撼，超过 4 级就失控 |

**纪律**：
- **一级一值，全项目只用一套比例**。混用 1.2 和 1.5 会出现"两个差不多大"的字号，读者会以为是失误。
- **正文:主标题 = 2–4 倍**。小于 2 倍 → 没有层级；大于 4 倍 → 标题吃掉版面（海报除外，海报可到 6–8 倍）。
- 阶梯值**取整到偶数**（16/20/24/32/40/48/64），避免 19.2px 这种"算得出、说不清"的值。

### 5.2 中文的字号修正

- 中文同字号**视觉上比西文小**（字面率低），整体 **+1–2px**：正文 16–18px（内容页）/ 14px（中后台）。
- 中文**不用 500 字重**：多数中文字体缺该档，浏览器会伪粗体（糊）。强调用**字号 + 颜色**，或直接用 600。
- 中文**不用斜体**（伪斜体，结构歪）。要强调用「着重号」或加粗 + 色。
- 标题字号 ≥ **24px** 时中文可上 700；< 20px 一律 ≤ 600，否则笔画糊成一团。

## §6 行长与行距（最影响"读得下去"的两项）

### 6.1 行长（measure）

**西文**（Butterick 原文）：
- **45–90 字符**（含空格），**2–3 个字母表**（`abcdefghijklmnopqrstuvwxyz` 排 2–3 遍）为可读区间。
- 报纸栏窄是因为**栏很高**——高栏必须窄，否则眼睛纵向追踪会丢行。
- 网页常见病：**通栏 1200px 正文**，一行 130+ 字符，读三行就串行。

**中文**：
- 正文 **25–40 字/行**（≈ 版心 400–640px @16px）；移动端 **15–20 字**。
- 中文没有词间空格，行长上限比西文更严：**超过 45 字，回行找首字会明显变慢**。
- 表格里的说明文字可短到 12–15 字，但**不得窄于 10 字**（频繁换行打断语义）。

### 6.2 行距（leading）

**西文**（Butterick 原文）：**120%–145%** 字号。低于 110% 太挤，高于 170% 太散。
- 字号越小、行长越长 → 行距要越大；反之可收紧。
- 联动公式（建议值）：`line-height ≈ 1.2 + (行宽字符数 − 45) × 0.005`。45 字符 → 1.20；90 字符 → 1.43。

**中文**：**1.6–1.8**（内容页）/ **1.5**（中后台紧凑）/ **1.8–2.0**（长文、适老）。
- 中文方块字没有上下伸部（ascender/descender），行距可以比西文更松而不散。
- 中文行距必须**取整到基线**：16px × 1.6 = 25.6 → 取 **24px（1.5）或 32px（2.0）**，不要 25.6px。

### 6.3 行长 × 行距联动表（直接用）

| 行长（字符） | 西文行距 | 中文行距 | 说明 |
|---|---|---|---|
| 30–45 | 1.15–1.25 | 1.5–1.6 | 窄栏、侧栏、图注 |
| 45–65 | 1.25–1.35 | 1.6–1.7 | **正文最佳区** |
| 65–90 | 1.35–1.45 | 1.7–1.8 | 长文、报告 |
| >90 | 禁止 | 禁止 | 拆栏或缩版心 |

### 6.4 段落间距 vs 首行缩进（二选一，不许并用）

| 方式 | 值 | 适合 |
|---|---|---|
| 首行缩进 | 中文 **2 字（2em）**；西文 **1em（不用 0.5″）** | 书、长文、连续阅读 |
| 段间距 | **0.75–1.0 × 行高**（16px 正文 → 12–16px） | 网页、卡片、扫描式阅读 |
| 两者并用 | ❌ | 视觉上出现"双重分段"，段落关系反而模糊 |

**中文特例**：首段**不缩进**（跟随标题），后续段缩进 2 字——这是书籍惯例；网页一律用段间距。

## §7 段落细节与断行（工艺层，差一点就差很多）

### 7.1 孤行与寡行（widows & orphans）

- **orphan（孤行）**：段落首行被留在页/栏底部，单独一行。
- **widow（寡行）**：段落末行被推到下一页/栏顶，单独一行。
- CSS 默认 `orphans: 2; widows: 2`（MDN）——**默认值只保证 2 行，专业排版要 3**。书籍建议 `orphans: 3; widows: 3`。
- 排版软件（InDesign）里对应「Keep Options → Keep with next / Keep lines together」。

### 7.2 断行算法（CSS 三件套）

| 属性 | 作用 | 限制（实测/文档） |
|---|---|---|
| `text-wrap: balance` | 均衡各行字数，**标题必用** | 只对**有限行数**生效：**Chromium ≤6 行、Firefox ≤10 行**（MDN）。超限自动退化 |
| `text-wrap: pretty` | 用更慢算法优化末行孤字，**正文用** | 有性能成本，只给长文块 |
| `hyphens: auto` | 西文自动连字符断词 | 需 `lang` 属性；中文不适用（中文靠避头尾） |
| `word-break` / `overflow-wrap` | 长 URL/英文串强制断 | `break-word` 只作兜底，不要给正文 |

**标题一行放不下时的正确顺序**：① 改文案（最有效）→ ② 缩字号一档 → ③ `text-wrap: balance` → ④ 手动 `<br>` 控制断点。**永远不要靠 `letter-spacing` 硬塞**。

### 7.3 标点悬挂（hanging punctuation）

- 西文：`hanging-punctuation: first last;` 让首行开引号/末行闭引号探出版心，**左边缘视觉才齐**。
- 中文：**标点挤压 + 悬挂**是 clreq 的核心诉求（句号、逗号不占满格）。CSS 侧 Safari 支持较好，Chromium 支持不完整 → **务实做法**：用 `text-spacing-trim`（新特性，渐进增强）+ 手动 `letter-spacing` 微调。
- **判断标准**：看左边缘的竖线，若被引号/括号顶出 1/4 字 → 需要悬挂；若文字块左边缘呈锯齿 → 说明标点全角占位没处理。

### 7.4 两端对齐（justify）的代价

- 中文：`text-align: justify` **可用且推荐**（方块字天然等宽，不会出现大河）。
- 西文：`justify` 在**窄栏（<45 字符）会产生"文字大河"（rivers）**，必须配 `hyphens: auto` 才勉强可用。**网页正文默认左对齐（flush left）**，justify 只用于印刷或宽栏。
- 最后一行：`text-align-last: left`（不要让它也撑满）。

## §8 视觉动线与焦点

### 8.1 三种动线模型

| 模型 | 路径 | 适用 |
|---|---|---|
| **Z 型** | 左上 → 右上 → 左下 → 右下 | 少内容落地页、海报、封面 |
| **F 型** | 顶部横扫 → 左侧竖扫 → 局部横扫 | 内容型页面、列表页 |
| **单点式** | 一个视觉重心，其余全部服务于它 | 海报、社媒图、开屏 |

**海报/社媒图一律用单点式**：先定"3 秒后用户记住的那一个东西"（一句话/一个数字/一张脸），其余元素降级为配角。

### 8.2 分割线与落点

- **三分法（rule of thirds）**：把画面切 3×3，主体放在**交点**上（0.333 / 0.667）。YouTube 官方缩略图指南明确推荐用三分法构图。
- **黄金分割落点**：**0.382 / 0.618**。比三分法更"稳"，适合需要安静感的海报。
- **不要同时用两套**：一张图里既按三分法又按黄金比放元素 → 看起来"哪都不对齐"。

### 8.3 视觉重量（判断"哪边重"）

按重量从大到小：**人脸/眼睛 > 高对比色块 > 大字号 > 深色块 > 图形 > 细线 > 留白**。
- 一张图**只允许一个"最重"元素**。出现两个 → 用户视线来回跳，3 秒测试必失败。
- 重量不对称时用**留白配平**：左边一个重色块，右边用大面积空白压住，而不是再加一个小元素。

## §9 留白与密度（留白占比）

| 载体 | 留白占比（建议值） | 说明 |
|---|---|---|
| 编辑型长文 | **30–45%** | 含页边距；低于 30% 显廉价 |
| 海报 | **40–60%** | 留白是海报的"贵气"来源 |
| 信息长图 | **20–30%** | 信息密度优先，但每屏必须有一个气口 |
| 后台/工具 | **15–25%** | 密度优先，靠分组而非留白 |
| 社媒图 | **35–50%** | 缩略图阶段，留白 = 可读性 |

**四条纪律**：
1. **留白不等于均匀**：重要元素周围留白更多，形成"呼吸不均"的节奏。
2. **边缘留白 < 内部留白**（视觉上）：版心内的段落间距应大于页边距的 1/2，否则内容像"贴在框上"。
3. **气口（每 3–5 个信息块后留一个大间距）**：长图没有气口 = 一堵墙。
4. **不要用留白修补**：元素少了不是"加留白"，是"加内容或换构图"。

## §10 海报（Poster）

### 10.1 尺寸与文件

| 规格 | 成品尺寸（mm） | 300ppi 像素 | 常见用途 |
|---|---|---|---|
| A3 | 297 × 420 | 3508 × 4961 | 桌面海报、展板小图 |
| A2 | 420 × 594 | 4961 × 7016 | **最常用**：校园/活动 |
| A1 | 594 × 841 | 7016 × 9933 | 户外展板 |
| A0 | 841 × 1189 | 9933 × 14043 | 大型展板（可降 150ppi） |
| B1 | 707 × 1000 | 8350 × 11811 | 电影海报惯例 |
| 50 × 70 cm | 500 × 700 | 5906 × 8268 | 国内印刷厂最常见非标尺寸（惯例） |
| 18 × 24 in | 457 × 610 | 5400 × 7200 | 北美惯例 |

ISO 216 规则：A 系列同一比例 **√2:1**，每级面积为上一级一半，**向下取整到毫米**；尺寸公差 ≤150mm 为 **±1.5mm**、150–600mm 为 **±2mm**、>600mm 为 **±3mm**。

### 10.2 出血与安全区（做错必被印厂退回）

| 项目 | 值 | 说明 |
|---|---|---|
| 出血（bleed） | **3mm**（公制通行）/ **1/8″=3.18mm**（英制） | 底色/图片必须延伸进出血区 |
| 大幅面海报 | **+6.35mm（0.25″）** | 大尺寸纸张位移更大 |
| 模切/异形 | **6mm（1/4″）** | 刀版位移容差 |
| 安全区（safe area） | 出血内再缩 **3–5mm** | 所有文字/logo 不得越过 |
| 裁切线（crop marks） | 出血外 **3mm** 处 | 距成品线，不是距出血线 |

**常见事故**：把底色做成"成品尺寸"→ 裁切后四边露白边 1–2mm。**底色画布 = 成品 + 出血 ×2**。

### 10.3 海报的信息层级（三层封顶）

| 层级 | 内容 | 占版面 | 字号（A2，观看 2m） |
|---|---|---|---|
| **L1 主张** | 一句话 / 一个数字 / 一个词 | **≥25%** | **120–400pt**（字高 40–140mm） |
| **L2 支撑** | 副标题、时间、地点、主讲人 | 10–15% | 36–72pt（字高 12–25mm） |
| **L3 细节** | 主办方、二维码、网址、赞助 | ≤8% | **≥18pt（6mm）** |

**远距离可读性经验公式（标牌行业惯例，非标准）**：字高（mm）≈ **观看距离（m）× 8**。
→ 3m 外要看清 → 字高 ≥24mm；10m 外 → ≥80mm。**这是下限，L1 主张应做到 3–5 倍。**

**信息量上限**：一张海报 **1 个主张 + ≤3 条支撑 + ≤1 个行动指令**。超过就不是海报，是传单。

### 10.4 海报构图四选一

| 构图 | 结构 | 适合 |
|---|---|---|
| **上下分割** | 上 2/3 图 + 下 1/3 字（或反之） | 活动海报，最稳，最不容易错 |
| **左右分割** | 竖切 1:1.618 或 1:2 | 有强人像/产品图时 |
| **中心放射** | 主体居中，文字环绕 | 演出、展览、需要"聚焦" |
| **满版出血** | 图铺满，字压在图上的留白区 | 视觉冲击，要求图本身够干净 |

**必查**：文字压在图上时，**局部对比度 ≥4.5:1**（不是整图平均）。做法：给文字区加**单向渐变遮罩**（黑 0%→60%），不要给整图加暗角。

## §11 长图（Long Image / 信息长图）

### 11.1 尺寸与字号换算（这一步错了整张图都小）

长图在手机上被**缩放到屏宽**显示，所以设计稿字号必须按比例放大：

| 设计宽度 | 缩放比（÷375pt 屏宽） | 正文最小字号 | 标题字号 |
|---|---|---|---|
| **750px**（微信旧标准） | 2.0× | **≥32px**（=16pt） | 56–72px |
| **1080px**（通用/小红书） | 2.88× | **≥44px**（≈15pt） | 80–104px |
| **1242px**（iPhone 3x 稿） | 3.31× | ≥50px | 92–120px |

**公式**：`设计稿字号 = 目标 CSS 字号 × (设计宽度 ÷ 375)`。目标 16px → 1080 宽时 = **46px**。写成 28px 的正文在手机上只有 9.7pt，**必被吐槽"字太小"**。

### 11.2 分段节奏（长图的真正难点）

- **一屏一个信息点**。屏高按 **1080 × 1.4 ≈ 1500px** 估算（手机可视区约 1.4 屏宽高比）。
- **每 3–5 屏插一个"气口"**（大留白 / 大图 / 分隔页），否则读者在中段流失。
- **首屏必须给钩子**：标题 + 一个数字/结论 + "往下还有 X 个点"的暗示。
- **末屏必须有落点**：总结一句话 + 行动（关注/收藏/扫码），不要以"谢谢观看"结尾。

### 11.3 切图与导出

- 单张高度 **≤ 20000px**（部分平台/工具上限），超出切成 2–3 段，**重叠 100–200px** 保证接缝连续。
- 接缝**不要切在文字行上**，切在留白带或图片区。
- 导出 **JPG 质量 85–90** 或 **WebP**；纯色块多的图用 PNG（避免 JPG 色带）。
- 长图**不要做圆角**（拼接后圆角只在首尾，中间是直角，很怪）。

## §13 印刷交付（设计做完不等于能印）

### 13.1 五个必查项

| 项目 | 标准值 | 说明 |
|---|---|---|
| **分辨率** | 成品尺寸下 **300ppi**；A1 以上 **150ppi** 可接受 | 图片在版面上被放大后仍要满足，不是"原图 300" |
| **色彩模式** | **CMYK**（印刷）/ RGB（仅屏幕） | 转换后**必须重新看一遍**：高饱和 RGB（如 #00FF00）在 CMYK 里印不出来 |
| **总墨量（TAC）** | **≤300%**（涂布纸）/ **≤240%**（新闻纸） | 四色黑（C100 M100 Y100 K100）= 400%，**必糊** |
| **黑场** | 正文黑用 **K100 单黑**；大面积黑用 **C40 M30 Y30 K100** | 单黑印小字才锐利；四色黑印小字会套印不准发虚 |
| **细线与最小字号** | 线 **≥0.25pt**（0.09mm）；字号 **≥6pt**（中文 ≥7pt） | 低于此值印刷会断线/糊字 |

### 13.2 字体与文件

- **字体转曲（outline）** 或**嵌入字体**。转曲后不能再改字，**保留一份可编辑源文件**。
- 交付 **PDF/X-4**（最兼容）或 PDF/X-1a（老厂）。**不要交 RGB 的 PDF 给印厂**。
- 图片**嵌入**（不是链接），分辨率达标的 TIFF/JPG；**不要用 PNG 带透明通道**（印厂处理透明易出白边）。
- 黑色文字**设叠印（overprint）** 或直接 K100——两者取一，问印厂。

### 13.3 纸张与工艺（影响设计决策）

| 变量 | 对设计的影响 |
|---|---|
| 纸张白度 | 高白纸会让浅色更浅，浅灰字要加深 |
| 涂布 vs 非涂布 | 非涂布吸墨，**细线要加粗、小字要加大** |
| 反光 | 铜版纸反光，深色大面积易留指纹 |
| 折页 | 折线处**不能放文字**（尤其跨折的标题） |
| 装订 | 胶装内页外侧要加 **3–5mm 爬移（creep）**补偿 |

## §14 CSS 实现（可抄）

### 14.1 编辑型网格（12 栏 + subgrid 对齐）

```css
.page {
  display: grid;
  grid-template-columns: repeat(12, minmax(0, 1fr));
  column-gap: 24px;
  max-width: 1200px;
  margin-inline: auto;
  padding-inline: 24px;
}
.article { grid-column: 3 / span 8; }      /* 正文 8 栏 */
.figure  { grid-column: 2 / span 10; }     /* 图 10 栏，出血感 */
.sidebar { grid-column: 11 / span 2; }

/* 卡片内部与主网格对齐（避免"卡片里的图和正文不齐"） */
.card {
  grid-column: span 4;
  display: grid;
  grid-template-columns: subgrid;           /* 继承父级栏宽与 gap */
}
```

**subgrid 关键事实**（MDN）：`grid-template-columns: subgrid` 让子网格**复用父级轨道尺寸**，`gap` 默认继承（可覆盖）；**子网格内行号从 1 重新计数**；**子网格维度不会生成隐式轨道**——自动放置超出时会挤进最后一轨，需要隐式行时不要在该维度用 subgrid。

### 14.2 长文排版（一次给全）

```css
.prose {
  max-width: 38em;            /* 中文 ≈ 38 字/行 */
  font-size: 17px;
  line-height: 1.75;          /* 落在 4px 基线：17×1.75≈30 → 取 32px 更稳 */
  text-align: justify;
  text-align-last: left;
  text-wrap: pretty;          /* 正文：优化末行孤字 */
  orphans: 3; widows: 3;
  hyphens: none;              /* 中文不用连字符 */
  line-break: strict;         /* 中文避头尾 */
  hanging-punctuation: first allow-end;
}
.prose h2 {
  font-size: 28px;
  line-height: 1.35;
  text-wrap: balance;         /* 标题：均衡断行（Chromium ≤6 行 / Firefox ≤10 行） */
  margin-block: 2.5em 0.8em;
}
.prose p + p { text-indent: 2em; margin-block: 0; }  /* 缩进方案：取消段间距 */
```

### 14.3 首字下沉（drop cap）

```css
.prose > p:first-of-type::first-letter {
  -webkit-initial-letter: 3;   /* 非 Baseline，需前缀回退 */
  initial-letter: 3;           /* 占 3 行，基线落在第 3 行 */
  margin-right: .08em;
  font-weight: 700;
}
```
**注意**（MDN）：`initial-letter: 3` 等价 `3 3`（sink = size）；`3 1` 是**凸起（raised）**效果。**中文不用首字下沉**（方块字下沉后与后续字基线错位，视觉很怪）。

### 14.4 多栏文本（杂志内页）

```css
.columns {
  column-count: 3;
  column-gap: 4mm;             /* 印刷 4–5mm */
  column-rule: 0.25pt solid #ddd;  /* 分隔线 ≥0.25pt，否则印不出来 */
  orphans: 3; widows: 3;
}
.columns h3 { break-after: avoid; }   /* 小标题不落栏底 */
.columns figure { break-inside: avoid; }
```

### 14.5 竖排（中文/日文传统版式）

```css
.vertical {
  writing-mode: vertical-rl;   /* 从上到下、从右到左 */
  text-orientation: mixed;     /* 西文/数字自动旋转 90° */
  line-height: 1.8;
  height: 60vh;                /* 竖排下"行长"是高度 */
}
/* 纵中横排（2–3 位数字保持正立，clreq） */
.vertical .num { text-combine-upright: all; }
```
clreq 要点：直排时**行由右向左**、**栏水平切割**、**书页由左页起**；西文单词顺时针旋转 90°，并在与汉字间加 **≤1/4 汉字宽**字距（行首行尾除外）；2–3 位数字用**纵中横排**。

### 14.6 图片按版心比例裁切

```css
.plate {
  aspect-ratio: 3 / 2;
  object-fit: cover;           /* 铺满裁切，不拉伸 */
  object-position: center 30%; /* 人像保留头部 */
  width: 100%;
}
```

## §15 中文版式专项（避头尾 / 标点 / 竖排）

| 项目 | 规则 | 数值/写法 |
|---|---|---|
| 字面 | 汉字与标点均为 **1:1 正方形**（clreq 原则） | 不要给中文加 `letter-spacing` 做"疏排"（会破坏方块对齐） |
| 破折号 | **占 2 个汉字宽**，不得拆到两行 | 用 `——`（两个 U+2014）或 U+2E3A |
| 省略号 | **6 点、占 2 字宽** | `……`，不是 `...` |
| 间隔号 | 大陆 **半字宽**；港台 **一字宽** | `·` |
| 中西混排 | 汉字与西文/数字间加 **≤1/4 字宽**空隙 | 手写 ` ` 或用 `text-spacing`；不要用全角空格 |
| 标点位置 | 大陆标点偏**字面左下**（横排）；港台居中 | 影响"看起来是否对齐" |
| 避头尾 | 行首禁 `，。、；：？！）】》」`；行尾禁 `（【《「` | `line-break: strict` |
| 字距 | 标题可 **-0.01 ~ -0.02em**（收紧）；正文 **0** | 负字距超过 -0.03em 会粘连 |
| 行首缩进 | **2 字（2em）** | 首段不缩进 |
| 竖排引号 | 用直角引号 `「」`，不用弯引号 | clreq |

**中文排版三条最常翻车的**：① 用 `letter-spacing` 拉大字距冒充"高级感"（方块结构散了）；② 用 `text-align: justify` 但不处理标点挤压（出现"孤字成行"）；③ 中英混排不加空隙（`2026年11月1日` 与 `2026 年 11 月 1 日` 视觉密度差一倍）。

## §17 反模式（20 条，逐条对照）

1. 正文通栏 1200px，一行 130 字符 —— 读者第三行就串行。
2. 页边距四边等分 —— 文字块视觉上下坠。
3. 首行缩进 + 段间距**同时用** —— 段落关系反而模糊。
4. 全项目混用两套字号比例 —— 出现"两个差不多大"的标题。
5. 中文加 `letter-spacing: 0.1em` 冒充高级感 —— 方块结构散了。
6. 中文用斜体强调 —— 伪斜体，笔画歪。
7. 中文用 500 字重 —— 多数中文字体无此档，浏览器伪粗体糊成一团。
8. 海报底色只做到成品尺寸，没留出血 —— 裁切后四边露白。
9. 海报所有信息同一字号 —— 3 米外一片灰，什么都读不到。
10. 长图正文按 28px 设计（1080 宽）—— 手机上只有 9.7pt。
11. 长图一屏塞 4 个信息点 —— 读者在第 2 屏划走。
12. 社媒图按 1080 全尺寸审美设计 —— 缩到 120px 缩略图全糊。
13. 社媒图关键信息放在会被平台裁掉的位置 —— 首图文字被切一半。
14. 四色黑（C100M100Y100K100）印正文 —— 总墨量 400%，糊且套印不准。
15. 细线 <0.25pt —— 印刷后断线或消失。
16. 交 RGB 的 PDF 给印厂 —— 颜色整体偏移，高饱和色印不出。
17. 图片"原图 300ppi"但在版面上被放大 3 倍 —— 实际 100ppi，糊。
18. 折页折线处放标题 —— 折完字被压断。
19. 竖排时用弯引号 / 西文不旋转 —— 排版规则错，读起来别扭。
20. 用留白修补"内容不足" —— 该加内容或换构图，不是加空。

## §18 自检（18 项，交付前逐条过）

**网格与版心**
1. 版心宽 ≈ 页宽 × 0.55–0.70？行长落在 45–90 字符 / 中文 25–40 字？
2. 下边距 ≥ 上边距（差值约 6mm）？非对称时差值 ≥25mm？
3. 所有垂直尺寸都是基线（4/8px）的整数倍？压暗后基线能连成等距横线？
4. 栏数是 12（或能整除的 4/6/16）？gutter 固定、栏宽流体？gutter ≈ 栏宽 1/4–1/3？

**字与段**
5. 全项目只用**一套**字号比例？正文:主标题在 2–4 倍？
6. 行距落在 120–145%（西文）/ 1.6–1.8（中文），且与行长联动？
7. 首行缩进与段间距**只用了一个**？
8. `orphans`/`widows` ≥3（不是默认 2）？标题设了 `break-after: avoid`？
9. 标题用了 `text-wrap: balance` 且行数在 Chromium 6 行内？
10. 中文：无斜体、无 500 字重、无 `letter-spacing` 疏排、标点全角、避头尾生效？

**构图与留白**
11. 3 秒测试：能说出唯一主角是什么吗？有没有两个"最重"元素打架？
12. 落点只用了一套（三分法 **或** 黄金比），没有混用？
13. 留白占比在目标区间（海报 40–60% / 编辑 30–45% / 长图 20–30%）？
14. 文字压在图上处，**局部**对比度 ≥4.5:1（不是整图平均）？

**交付物**
15. 海报：底色画布 = 成品 + 出血×2？文字全在安全区内（再内缩 3–5mm）？L3 字号 ≥18pt？
16. 长图：设计稿字号 = 目标字号 × (设计宽 ÷ 375)？单张高 ≤20000px？接缝不在文字行上？
17. 社媒图：缩到 120px 还认得出主标题？关键信息避开了各平台裁切区？
18. 印刷：300ppi / CMYK / 总墨量 ≤300% / 正文 K100 / 细线 ≥0.25pt / 字体转曲 / PDF-X4？
