# 18 · 数据表空态迁移

## 任务（一句话）

后台「工单列表」带状态 / 负责人 / 时间三个筛选器并与 URL 同步；设计「有数据 → 筛选无结果 → 清除筛选 → 数据恢复」的全过程，同时覆盖加载、错误与无权限。

## 目标用户与场景

- 用户：客服主管，日均筛 30 次；会把带筛选的 URL 发给同事；一半时间用键盘。
- 场景：先筛「未解决 + 我负责」，发现 0 条后怀疑筛错，清除一个条件再试；中途会勾选多行准备批量转派。
- 前置认知：熟悉 Excel 筛选；把「共 0 条」当结果，不当错误；最怕勾选被悄悄清掉或页面跳回第 1 页。

## 硬约束

- 载体：SPA 后台，内容区 1280px；筛选状态写入 URL；分页 20 条/页；支持跨页批量选择。
- 品牌：沿用现有 token；「无结果」不得用红色表达，红色只留给失败。
- 合规：筛选变化后读屏需知道结果数变化；不得每次击键都播报；批量选择不得跨筛选静默残留。
- 交付：loading / empty / error / forbidden 四态 + 迁移时序 + 焦点与播报说明。

## 必须回答的 3 个问题

1. 四种「空」在数据层如何区分，为什么不能用一个 `length === 0` 分支接住？
2. 筛选、分页、批量选择在状态迁移时各自保留什么、丢弃什么？
3. 读屏如何知道「从 12 条变成 0 条」而不被每次输入打断？
