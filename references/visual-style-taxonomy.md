# 视觉风格谱系与设计运动（Visual Style Taxonomy）

> 快照 2026-11-07 · 一句话立场：**风格不是名词贴标签，是「视觉信号的组合签名」**。用户说"做成 XX 那种感觉"的本质，是把一个模糊形容词，拆成可执行的「字体 / 色彩 / 形状与材质 / 动效与空间」四组信号，再落成 token。直接套"极简""高级""科技感"六个字，等于把品牌差异退化成留白+灰字+细线。

---

## 0. 什么时候读这份文件

- 用户说"做成 Linear / Vercel / 某站那种感觉""这个风格叫什么""帮我定个视觉调性""想要高级感 / 复古感 / 科技感 / 温暖感"。
- 第 4 步 L2 风格级匹配、第 5 步「视觉风格谱系」原则、第 6 步「风格关」自检。
- 与 `design-md-format.md` §3 品牌 DNA（长期资产）互补：本文件是"临时 / 竞品 / 潮流风格"的速配与拆解工具，不替代品牌个性三词定位。

---

## 1. 为什么需要风格谱系（核心立场）

1. **"高级感""复古感"是结果不是方法。** 追问一句：它具体是哪几组信号？说不出信号的形容词，不能作为设计指令。
2. **风格 = 四维信号的组合签名**（见 §2）。同一个词在不同语境指向完全不同的信号集——"高级"在奢侈品是极致留白+衬线+低饱和，在科技产品是克制网格+单色调+轻投影。先拆再选，不能直接抄词。
3. **风格是手段，品牌个性是约束。** 三词定位（见 `brand-identity.md` §3）决定"该成为谁"，风格只决定"用哪套视觉语言把个性说出来"。风格服务于个性，不替个性。
4. **趋势有保质期。** 纯视觉潮流（新拟态、玻璃拟态）从引爆到过载往往 12–24 个月；一次只上一种材质语言，叠满 = AI slop（见 `ai-design-toolchain.md` §11）。

---

## 2. 风格识别四维信号（拆任何风格都用这四把尺）

拿到一个参考图 / 一个站点 / 一个形容词，**逐维标注**，不要整体感受。四把尺：

### 2.1 Typography（字）
- 字族：衬线（权威 / 传统 / 编辑）· 无衬线（中性 / 现代 / 科技）· 等宽（技术 / 复古终端 / 代码感）。
- 字重对比：单字重（极简）· 强对比（标题特粗+正文细，张扬）· 可变。
- 字号节奏：比例阶（建议 `1.2 / 1.5 / 2.0 / 3.0` 一类固定阶，见 `design-tokens.md`）vs 随意。
- 字距与对齐：紧字距（现代紧凑）· 宽字距大写（高级 / 标签）· 左对齐 / 居中 / 不对称网格。

### 2.2 Color（色）
- 色相范围：单色相（克制，如 Vercel 近黑白）· 撞色（张扬，如 Neo-brutalism）· 全谱（玩趣，如 Memphis）。
- 饱和度 / 明度策略：高饱和（能量）→ 去饱和（高级 / 企业）→ 全灰阶（极简）。
- 明暗基调：浅底深字（主流）· 深底浅字（科技 / 暗色，见 `dark-mode.md`）· 高对比单色（Brutalism）。
- 对比与渐变：硬边平涂（Flat）· 柔和同相渐变（Soft UI）· 高光水珠（Y2K）· 霓虹 glow（Cyberpunk）。

### 2.3 Shape & Material（形与材质）
- 圆角档：**0（硬 / 工业 / 原始）· 4（微圆 / 严谨）· 8（中性）· 16（友好）· 全圆（亲和 / 可爱）**。一次只主导一档。
- 深度语言（最关键、最易冲突）：扁平（Flat）· 轻投影（Material / 现代 SaaS）· 强投影（Neo-brutalism 硬黑边）· 拟物（Skeuomorphism）· 玻璃（Glassmorphism）· 新拟态（Neumorphism 同源双色内阴影）· 黏土（Claymorphism 软高光）。
- 描边：无描边 · 1px 细线（克制）· 2–3px 硬黑边（Neo-brutalism）。
- 纹理与装饰密度：无纹（极简）· 几何碎形（Memphis）· 网格扫描线（Cyberpunk / Vaporwave）· 留白为主。

### 2.4 Motion & Space（动效与空间）
- 动效密度：静态（极简 / 编辑）· 克制（轻 hover / 淡入，现代 SaaS）· 活泼（弹性 / 交错，年轻产品）。
- 留白量：满版（Maximalism）· 均衡 · 极致留白（Minimalism / 奢侈品，留白占比可到 40–60%，见 `editorial-layout.md` §16）。
- 栅格严格度：数学网格（Swiss / 企业，见 `editorial-layout.md`）· 自由 · 卡片网格（Bento）。

> **可抄清单**：标注任何风格都先填这张四维表，缺一项就不算"看懂了风格"。

## 3. 主流动派谱系（编年 + 视觉签名 + 何时用 / 不用 + 代表）

每条给：起源年份与关键人物、四维签名、代表、何时用、何时不用。**年份与人物以权威史料为准**（Swiss 1950s / Müller-Brockmann；Bauhaus 1919 / Gropius；Memphis 1981 / Sottsass；iOS 7 扁平 2013；Material Design 2014 / Google I/O；Neumorphism 2019 / Plyuto 引爆、Jason Kelley 在 Malewicz 文章评论区造词、Malewicz 去 "o" 定型；Glassmorphism 2020 / Malewicz 命名）。

> **一处易错史料（2026-11-07 核对原文修正）**：常见二手写法是「Neumorphism 由 Michal Malewicz 命名」，**不精确**。Malewicz 本人 2019-12-17 在 UX Collective 原文写的是：*"This 'New skeuomorphism' has been called by **Jason Kelley** Neuomorphism in the comments. I decided to skip the 'o' and the name … came alive."* 即：**视觉由 Alexander Plyuto 的 Dribbble 作品《Skeuomorph Mobile Banking》引爆（2019）→ Jason Kelley 在评论区造词 Neuomorphism → Malewicz 去掉 "o" 定型并推广为 Neumorphism**。写品牌 / 设计史文案时按这三层归属，别把推广者当唯一造词者。

### 3.1 Swiss / International Typographic Style（瑞士国际主义，1950s）
- 签名：数学网格、无衬线（Helvetica / Akzidenz-Grotesk）、不对称构图、左对齐、大字号标题、摄影替代插画、留白即结构。
- 代表：Josef Müller-Brockmann 音乐海报、国际主义平面。
- 用：数据报告、编辑设计、金融、需要"理性可信"的场景。不用：需要温度 / 玩趣 / 强个性的消费品牌。

### 3.2 Bauhaus（1919–1933，Walter Gropius）
- 签名：几何基本形（圆 / 方 / 三角）、三原色 + 黑白、无衬线、形式跟随功能、红黄蓝撞色。
- 用：教育机构、艺术馆、强调"现代 / 理性"的视觉。不用：需要柔和 / 高级感的奢侈品。

### 3.3 Brutalism（网页野兽派，2014+）
- 签名：近乎原始 HTML、系统默认字体、高对比单色、无圆角无阴影、露出结构、故意"未抛光"。
- 用：个人作品集、艺术家、反主流表达。不用：企业 / 金融 / 任何要"可信"的产品（可读性靠强对比保住）。

### 3.3b Neo-brutalism（新野兽派，2020+）
- 签名：硬黑描边（2–3px）、硬投影（offset 实色块）、高饱和撞色、故意粗糙、大圆角但硬边。
- 用：年轻 / 张扬 / 初创、活动页。不用：金融 / 政府 / 需要克制的 B 端。

### 3.4 Memphis（1981，Ettore Sottsass）
- 签名：几何碎形、撞色块、黑白条纹 / 波点图案、玩趣、无统一网格。
- 用：儿童、活动、品牌个性强的传播物料。不用：信息密集的工具型界面（噪声淹没信息）。

### 3.5 Skeuomorphism（拟物，2007–2013，iOS 6 峰值）
- 签名：材质仿真、高光、内阴影、真实纹理（皮革 / 木纹）、强投影。
- 用：**已基本被扁平取代**；仅限需要"物理隐喻"的教学 / 儿童 / 特定怀旧场景。不用：现代通用产品（已被判为过度装饰）。

### 3.6 Flat Design（扁平，2013+，iOS 7 / Windows 8 Metro 引爆）
- 签名：纯色块、无阴影无渐变、简单几何图标、二维。
- 用：**当今大多数产品的基线**；安全、中性、信息优先。注意：纯扁平缺层级，需靠颜色 / 间距 / 描边补"可点击"信号（见 `patterns.md`）。

### 3.7 Material Design（2014，Google）
- 签名：8dp 栅格、elevation（z 轴阴影分层）、涟漪反馈、浮动按钮、系统化的动效曲线（见 `motion-system.md`）。
- 用：Android / Google 生态、需要"系统化层级"的产品。不用：要强烈差异化的品牌（容易"一看就是 Material"）。

### 3.8 Neumorphism / Soft UI（新拟态，2019–2020，Plyuto 引爆 / Kelley 造词 / Malewicz 定型）
- 签名：**同源双色背景 + 单光源一对方向相反的内阴影**，大圆角，元素像"从背景浮起 / 按下去"。**可访问性 / 表单红线**：低对比违背非文本 3:1，绝不做主操作按钮或表单输入。
- ⚠️ **可见性陷阱**：元素与背景对比极低，控件边界靠阴影暗示，**在弱光 / 低对比 / 色觉障碍下基本不可辨**，且违背 `accessibility.md` §2 的非文本 3:1。只用于装饰性 / 低频控件，**绝不做主操作按钮或表单输入**；暗色下直接崩（见 `dark-mode.md`）。

### 3.9 Glassmorphism（玻璃拟态，2020+，Malewicz 命名）
- 签名：半透明表面 + 背景模糊（backdrop-filter）+ 1px 高光描边 + 轻投影 + 饱和背景图。**可访问性 / 对比度红线**：文字 ≥4.5:1、正文密集区禁用、低端机须测 backdrop-filter 成本（详见本节）。
- ⚠️ **对比度陷阱**：半透明会压低文字与图标的实测对比度，必须保证文字 ≥4.5:1（叠暗化层 / 加实色底）；**不可用于正文密集区**；`backdrop-filter` 在低端机与部分浏览器昂贵（见 `performance-design.md` §11）。用：卡片叠层 / 悬浮面板 / 科技感 Hero。不用：长文 / 表单 / 弱网。

### 3.10 Minimalism（极简，长青）
- 签名：极致留白（40–60%）、极少元素、无装饰、单一强调色、克制的字重。
- 用：奢侈品、内容优先、高端 SaaS、摄影 / 作品集。不用：信息密集的工具（留白不能替信息层级）。

### 3.11 Maximalism（极繁，周期）
- 签名：满版、撞色层叠、多字体混排、强图案。
- 用：节日、潮流、亚文化、表达型海报。不用：B 端 / 金融 / 任何要"可信 / 可读优先"的场景。

### 3.12 Y2K / Frutiger Aero（2004–2013，近年回流）
- 签名：气泡、高光水珠、玻璃质感、天空蓝 + 银白、圆润、乐观未来感；Frutiger Aero 是"玻璃 + 自然 + 气泡"子型。
- 用：消费、Gen-Z、怀旧营销、乐观主题。回流信号强（2023+ 在社媒 / 包装回潮），但**仅做点缀或主题，不做全站基线**。

### 3.13 Vaporwave / Retro-futurism（2010s，亚文化）
- 签名：粉紫青渐变、网格地平线、故障（glitch）、罗马雕塑 / 日文假名、复古 3D。
- 用：音乐、亚文化、艺术海报、限时活动。不用：严肃 / 企业产品。

### 3.14 Cyberpunk / Dark tech（暗色科技）
- 签名：暗底、霓虹（青 / 品红 / 绿）、扫描线、等宽字体、发光描边。
- 用：游戏、开发者工具、暗色产品的氛围层。注意：霓虹在暗底上易过饱和刺眼，且叠加玻璃 / 渐变会放大对比度风险（见 `dark-mode.md` §3）。

### 3.15 Bento grid（便当盒栅格，2022+，Apple / Linear 推动）
- 签名：圆角卡片网格、内容块化、每格一信息、留白内嵌。
- 用：落地页概览、仪表盘、功能清单、"一屏看全局"。注意：格子数 ≤6 为宜，过多回到"卡片堆"。

### 3.16 Claymorphism（黏土拟态，2022+）
- 签名：圆润如充气、双软阴影（内暗外亮）、高光点、糖果色。
- 用：可爱、消费 App、儿童、营销插画。不用：严肃 / 数据密集。

### 3.17 Corporate / Enterprise（企业中性，长青基线）
- 签名：中性蓝 / 灰、规整栅格、低饱和、信息密集但有序、弱投影。
- 用：B 端、金融、政府、SaaS。这是"不出错"的默认，但易平庸——用 token 与清晰层级拉开差异，而非靠风格出彩。

## 4. 风格匹配决策（给定"A 感觉"，怎么拆成信号）

### 4.1 用户给参考图 / 站点（最常见、最可靠）
四步：**截三屏**（首屏 / 列表 / 详情）→ **逐维标注**（按 §2 四维表填，而不是"好看"）→ **抽公共信号**（多个参考的交集才是真需求）→ **落成 token**（圆角档 / 阴影档 / 色板基调 / 字号阶 / 字重对比 / 间距基调 / 动效密度）。

### 4.2 用户给形容词（"高级 / 复古 / 科技 / 温暖"）
把词翻成信号，避免空转：
- **高级**：去饱和、单一强调色、强字重对比或极致留白、细描边、克制动效。
- **复古**：Y2K / 80s（撞色 + 圆润 + 高光）或做旧色板（低饱和米黄 + 颗粒）；先问清是哪段"复古"。
- **科技**：冷色系、几何无衬线、轻投影 / 玻璃、暗色可选、规整栅格。
- **温暖**：暖色相（橙 / 红 / 米）、圆角偏大、柔和阴影、人文衬线、留白中等。
- **可信 / 专业**：企业中性（§3.17）、清晰层级、低饱和、克制动效。
- **年轻 / 张扬**：Neo-brutalism / 撞色 / 活泼动效，但守住可读性与对比度。

### 4.3 风格 vs 品牌（不替个性）
先用 `brand-identity.md` §3 定三词定位与反义词；风格只是"把个性翻译成视觉语言"的若干候选之一。若风格与个性冲突（如"温暖亲子"却套"硬黑边野兽派"），回退到个性，风格让步。

### 4.4 与第 4 步 L2 衔接
`design-md-format.md` §3 品牌 DNA 是长期资产；本文件是竞品 / 潮流风格的速配。匹配顺序：先 DNA（长期）→ 再本文件（临时 / 参考）。

## 5. 混搭的纪律（什么能混、什么冲突）

1. **安全混搭**：材质层（轻投影 / 玻璃）可叠任意色系；栅格严格度独立于色系；圆角档与色系独立。
2. **深度语言只能有一种主导**：拟物 + 扁平、玻璃 + 硬边阴影、新拟态 + 强投影 都打架——同一界面只选一套 depth language。
3. **装饰密度只能有一个极端**：要么极致留白（Minimalism），要么满版（Maximalism），中间态最易"说不清"。
4. **趋势叠加上限 = 1**：渐变 / 玻璃 / 3D / 新拟态 / 故障 同时出现 = AI slop（`ai-design-toolchain.md` §11）。只留一种材质语言做表达，其余收为基线。
5. **撞色有纪律**：Neo-brutalism / Memphis 的撞色是"刻意不安"，但**功能色（红=错误 / 绿=成功）必须回归语义**（见 `accessibility.md` §12），别让装饰撞色吃掉状态色。

## 6. 趋势生命周期（何时该上、何时已过）

1. **趋势曲线**：引爆（Dribbble / Beh开发者奖）→ 主流采纳 → 过载（一键模板化）→ 反噬（回到克制）。纯视觉潮流通常 12–24 个月走完前两段。
2. **技术 / 平台驱动的趋势值得跟**（暗色模式、容器查询、可变字体）：它们解决真实问题，不是审美赌博。
3. **纯视觉潮流谨慎**（新拟态、玻璃拟态、黏土）：上之前问"它是不是只解决'看起来新'"。
4. **过期信号**：满屏都是、工具一键生成同款、被 meme / 表情包化 → 该收手。
5. **长青 vs 周期**：Swiss / Minimalism / 企业中性 长青；Memphis / Y2K / Vaporwave 是周期回归，用作主题点缀而非全站基线。

## 7. 中文 / 出海场景的风格注意

1. **中文界面**：中文笔画密度远高于拉丁字母，极简留白要更克制（别为了"高级"把中文压到 12px）；字重与字距调整见 `chinese-design.md`（禁伪粗 / 伪斜、行高 ≥1.6）。衬线中文（宋体类）在屏幕小字号下易发虚，屏幕优先用黑体类。
2. **出海**：风格是文化信号——德语区偏好严谨网格、日本偏好克制留白、北欧偏好低饱和自然色；勿用刻板符号（如"中国风=龙"）替代真实文化偏好；图标 / 颜色 / 图像需本地复核（见 `i18n-localization.md` §15）。
3. **暗色 + 玻璃 / 霓虹**：对比度风险叠加，按 `dark-mode.md` §3 与 §6 双查，不得只靠"看着还行"。

## 8. 把风格转成 token（与 design-tokens.md 对接）

1. **风格 → token 映射表**（一次只定一套）：

| 风格意图 | 落地的 token 维度 | 取值建议 |
|---|---|---|
| 克制 / 科技 | 圆角 | `--radius: 8px`；阴影 `--shadow: 0 1px 3px rgba(0,0,0,.12)` |
| 友好 / 消费 | 圆角 | `--radius: 16px`；阴影更柔 |
| 张扬 / 年轻 | 描边 | `--border: 2px solid #111` + 硬投影 |
| 高级 / 奢侈品 | 字重对比 | 标题 700 / 正文 400；单一强调色 |
| 玻璃科技 | 表面 | `--surface-glass: rgba(255,255,255,.12)` + `backdrop-filter: blur(12px)` + 高光描边 |
| 暗色科技 | 基调 | 暗底（非纯黑，见 `dark-mode.md`）+ 霓虹 accent（谨慎，过饱和收 30%） |

2. **用 DTCG token 固化**（见 `handoff-collaboration.md` §13 / `multi-brand-theming.md`）：风格切换 = 换一组 semantic token，而不是重写 CSS；同一套 primitive token 可被多个"风格主题"引用。
3. **风格不是新 CSS，是 token 组合**：把 §2 四维标注直接落成 `--radius / --shadow / --font-display / --color-accent / --space-scale / --motion-density` 一组变量，交付时给开发这一组而非截图。

## 9. 12 场景速查

1. 用户说"做成 Linear 那种感觉" → §4.1 拆：暗色可选 / 克制无衬线 / 轻投影 / Bento 卡片 / 极克制动效。
2. 用户要"高级感"却给不出参考 → §4.2 走"高级"信号；先确认是"奢侈品高级"还是"科技高级"（信号不同）。
3. 全站想用新拟态 → §3.8 警告：只装饰 / 低频，主操作与表单禁用，暗色禁入。
4. 想用玻璃拟态做卡片 → §3.9 + §8：保证文字 ≥4.5:1，正文区禁用，低端机测 `backdrop-filter` 成本。
5. 品牌是"温暖亲子"却想套暗色霓虹 → §4.3：个性优先，风格让步，改用暖色 + 大圆角。
6. 潮流风格想"全站都上" → §5.4：只留一种材质语言。
7. 中文产品想极简 → §7.1：留白更克制，字号 ≥14px，黑体优先。
8. 出海产品定风格 → §7.2：按目标市场文化信号，不套刻板符号。
9. 拿不准该不该跟某个潮流 → §6：技术驱动跟、纯视觉谨慎、看是否已被 meme 化。
10. 设计评审里有人说"不够高级" → §2 + §4.2：把形容词翻成具体信号再讨论，不和稀泥。
11. 同一产品风格前后不一致 → §5 + §8：检查 depth language 与装饰密度是否只各一个。
12. 把参考站风格交付给开发 → §4.1 + §8：给 token 组，不给截图。

## 10. 20 反模式

1. 直接把"极简 / 高级 / 科技感"当设计指令，不拆信号。
2. 套"极简"退化为"留白 + 灰字 + 细线"，丢失品牌差异。
3. "温暖"却用冷色高饱和霓虹。
4. 全站同时上渐变 + 玻璃 + 3D + 新拟态（AI slop）。
5. 新拟态做主按钮 / 表单输入（可见性崩）。
6. 玻璃拟态压正文、文字对比度不达标。
7. 拟物回潮用在通用产品（过度装饰）。
8. 撞色装饰吃掉状态色（红绿橙黄被当装饰）。
9. 同一界面两套深度语言打架（拟物 + 扁平）。
10. 装饰密度两头不到岸（既非极简也非极繁）。
11. 趋势已过（被模板化 / meme 化）仍全站采用。
12. 中文界面照搬拉丁极简，12px 宋体发虚。
13. 出海套刻板文化符号（"中国风=龙"）替代真实偏好。
14. 暗色 + 玻璃 + 霓虹三层对比度风险叠加不查。
15. 风格替品牌个性做主（"做成网红风"压过三词定位）。
16. 给开发截图而非 token 组，还原度靠猜。
17. 圆角档一产品多档混用（0/8/16 同时出现）。
18. 用潮流掩盖信息层级缺失（"酷"但找不到按钮）。
19. 把 Neo-brutalism 的硬黑边用到金融 / 政府（可信度掉）。
20. 只抄视觉不抄约束（学了玻璃拟态却不懂对比度与性能代价）。

## 11. 20 自检（交付前逐条过）

1. 用户的需求（参考图 / 形容词）被拆成了 §2 四维信号，不是停在"感觉"？
2. 若给形容词，是否确认了它在本案语境的具体信号（"高级"是哪个分支）？
3. 风格是否服务于品牌三词定位，而非替个性做主？
4. depth language 全站是否只一种主导（无拟物+扁平打架）？
5. 装饰密度是否只有一个极端（极简 / 极繁），而非中间态？
6. 是否只上了一种材质 / 潮流语言（无多潮流叠加）？
7. 若有新拟态，是否仅装饰 / 低频，且避开了主操作与表单、暗色？
8. 若有玻璃拟态，文字对比度是否 ≥4.5:1、正文区是否禁用、低端机是否测过 `backdrop-filter`？
9. 圆角档是否全站统一（一产品一档）？
10. 功能色是否回归语义，没被装饰撞色吞掉？
11. 中文界面字号是否 ≥14px、黑体优先、行高 ≥1.6？
12. 出海风格是否按目标市场文化信号，未用刻板符号？
13. 暗色 + 玻璃 / 霓虹是否双查了对比度（见 dark-mode §3 / §6）？
14. 趋势是否值得跟（技术驱动 vs 纯视觉），是否已被 meme 化？
15. 风格是否被落成 token 组（而非仅截图）交付开发？
16. 参考站拆解是否走了 §4.1 四步（截三屏→逐维标注→抽交集→落 token）？
17. 字体选择是否与风格一致（衬线=权威传统，等宽=技术复古，无衬线=现代中性）？
18. 留白量是否与风格匹配（极简 40–60% / 编辑 30–45%），未在信息密集处过度留白？
19. 动效密度是否与风格一致（极简静态 / 现代克制 / 年轻活泼），且守 `motion-system.md` 时长？
20. 最终风格是否与同产品其余页面一致（同一套 token，无孤立样式）？

## 12. 可抄代码 / 清单

**风格速查卡（标注参考站用）**：
```
风格拆解四维表
├─ Typography：字族___ 字重对比___ 字号阶___ 字距___ 对齐___
├─ Color：色相范围___ 饱和策略___ 明暗___ 对比___ 渐变___
├─ Shape&Material：圆角档___ 深度语言___ 描边___ 纹理/密度___
└─ Motion&Space：动效密度___ 留白量___ 栅格___
```

**把"玻璃科技感"落成 token（CSS 变量）**：
```css
:root {
  --radius: 16px;
  --surface-glass: rgba(255, 255, 255, 0.12);
  --surface-glass-border: rgba(255, 255, 255, 0.35);
  --shadow-glass: 0 8px 32px rgba(0, 0, 0, 0.24);
  --color-accent: #6ea8fe;            /* 霓虹收 30% 饱和 */
}
.glass-card {
  border-radius: var(--radius);
  background: var(--surface-glass);
  border: 1px solid var(--surface-glass-border);
  box-shadow: var(--shadow-glass);
  backdrop-filter: blur(12px);          /* 低端机加 @supports 降级 */
}
```

**风格过期自检（给设计评审）**：
```
□ 这个潮流是否已被模板化 / meme 化？
□ 它是技术驱动（跟）还是纯视觉赌博（谨慎）？
□ 全站是否只上了一个材质语言？
□ 它是否压住了信息层级与对比度？
```
