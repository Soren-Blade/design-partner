# 元素设计模式图鉴 — Patterns（深度蒸馏）

> agent 的「设计语汇库」：高频界面元素的构型谱系、关键尺寸、风格变体与速配规则。**凡元素级需求（导航栏/Hero/页脚/CTA/定价…）先读本文件，按「构型 → 参数 → 变体 → 速配」四步给出设计本体，而不是给网站链接。** 所有数值经一线组件库（shadcn/ui、Tailwind UI、Preline 等）交叉验证。快照 2026-10-29

---

## 导航栏 Navbar

**构型谱系**（选 1 种，不混用）：
- **A 经典单行**：logo 左 | 链接右 | 主 CTA 最右端。高 64px（区间 56–72）。适用：工具/SaaS/绝大多数产品
- **B 透明叠覆**：叠在 Hero 大图上，滚动超过 24px 后变实底（或毛玻璃）。适用：品牌官网、视觉驱动
- **C 居中对称**：logo 居中，链接左右均布。适用：品牌站、时尚/奢侈品调性
- **D 浮动胶囊**：居中悬浮 pill，圆角 999px + 阴影。适用：作品集、创意工作者
- **E 双行**：上行 logo+账户/CTA，下行分区链接。适用：内容量大（文档站、电商）
- **F 侧边固定**：竖排图标+标签，宽 240–280px（可折叠至 64px 图标列）。适用：仪表盘/后台
- **移动端**（≤768px）：一律折叠为汉堡菜单 → 抽屉或全屏菜单；底部 Tab 若有则 5 项以内

**关键参数**：左右内边距 16–24px；链接字号 14px、间距 24–32px；logo 高 24–32px；主按钮高 40–44px；粘性导航 `position: sticky` + 最高 z-index。
**风格变体**：实底 + 1px 底边线（最稳）｜毛玻璃 `blur(12px)` + 72–85% 不透明度｜透明叠映（文字需保证与背景对比）｜深浅双主题各一套色板。
**速配**：开发者工具→A；品牌官网→B/C；作品集→D；后台→F。
**常见错误**：链接 >7 项；主 CTA >1 个；透明导航文字压在花图上对比度不足；汉堡菜单 >5 项主链接。

## 首屏 Hero

**构型谱系**：
- **A 居中聚焦**：大标题（48–72px）+ 一句副文 + 主/次 CTA 居中排布。转化最稳，SaaS 默认
- **B 左文右物**：左文案右产品截图/终端窗/插画，上下居中。信息型产品
- **C 全幅视觉**：一张大图/视频/3D 铺满，文字叠放。品牌冲击力
- **D 分屏对比**：左右两半（如深浅色、前后状态）。讲"转变"的故事
- **E 打字机/动态演示**：标题或窗口内有活的内容动效。开发者工具

**关键参数**：内边距上下 96–160px；标题 ≤2 行（移动端 32–40px）；副文 18–20px、行长 ≤36em、≤2 句；主次 CTA 并排间距 16px；社会证明（logo 墙/数据）距 CTA ≥48px。
**E 变体要点**：终端窗用等宽字体 14px、圆角 8px、边框+阴影，内容 ≤6 行。
**速配**：不明就绪选 A；有产品截图必选 B；纯品牌选 C。
**常见错误**：标题 >2 行；副文写成段落；CTA 超过 2 个；首屏塞表单（除非核心动作就是注册）。

## 功能特性区 Features

**构型谱系**：3 列网格（最常用）｜2×2 大卡｜左右交替图文｜密集列表（每行 icon+标题+一句话）。
**关键参数**：卡片内边距 24px、卡间距 24px；图标 24–32px 统一线宽；特性标题 18–20px；描述 14–16px ≤2 行；一屏 ≤6 项。
**要诀**：层级靠「图标→标题→描述」固定节奏；标题写利益（"秒级热重载"）不写功能（"热重载功能"）。

## CTA 区块

**构型谱系**：通栏色块（强调色底+白字居中）｜描边卡片（浅底+边框+左右布局）｜全宽渐变（每页 ≤1 处）。
**关键参数**：上下内边距 48–96px；标题 24–32px；按钮 44px 高；与正文区间距 ≥64px；一页 CTA 区块 ≤2 个。
**要诀**：副文案消除顾虑（"免费开始 · 无需信用卡"）；主按钮文案写动作与结果（"创建免费账户"优于"提交"）。

## 页脚 Footer

**构型谱系**：4 列链接 + 底条（产品/资源/公司/法务）｜精简单行（logo+少量链接+版权，作品集）｜大字标语式（品牌宣言压底）｜站点地图式（SaaS 大站）。
**关键参数**：上内边距 64–96px；列间距 32–48px；链接 14px 行高 2.0；底条（版权+社交图标）与正文列间距 48px，加 1px 顶边线。
**要诀**：链接按用户任务分组而不是按公司部门；社交图标 20px 统一单色。

## 定价表 Pricing

**构型谱系**：3 档横排（推荐档抬高/描边强调）｜2 档对照+企业档横条｜月/年切换（年付标 -20% 类折扣）。
**关键参数**：卡内边距 32px；价格数字 40–48px + 货币符号 0.5em 上标；特性列表行高 2.0，逐行勾选图标；推荐档用「描边 2px 强调色 + "最受欢迎"角标」而非放大。
**要诀**：三档定价中档设为默认推荐（折中效应）；企业档不标价写"联系销售"；免费档放最左。

## 登录/注册 Auth

**构型谱系**：居中卡片（≤400px，logo+标题+表单+社交登录+切换链接）｜左品牌右表单分屏（品牌侧放图/标语）｜全屏极简（只有表单）。
**关键参数**：输入框高 44–48px、圆角 8px、标签 14px 独立一行（不用占位符代替标签）；主按钮全宽 44px；错误信息红字置于字段下方 12px。
**要诀**：社交登录按钮置顶（图标+文字等宽）；注册表单 ≤4 个字段，能省则省。

## 仪表盘 Dashboard

**构型谱系**：侧边导航 F + 顶栏 + 内容区（默认）｜顶部导航 + 卡片网格（轻量工具）｜三栏（列表+详情+属性面板，管理类）。
**关键参数**：内容区内边距 24–32px；卡片圆角 8–12px、间距 16–24px；指标卡：数值 28–32px + 环比小字 + 迷你趋势图；表格行高 48–56px、表头 12px 大写灰字。
**要诀**：一屏只讲一个主任务；空状态给出下一步动作按钮，不只放插画。

## 卡片 Card

**构型谱系**：竖版图文（封面 16:9 + 标题 + 摘要）｜横版列表行（缩略图 48–64px + 双行文字）｜数据卡（数值+标签+趋势）｜可交互卡（hover 抬升 2px + 阴影加深）。
**关键参数**：内边距 24px；圆角 8–12px 全站统一；边框 1px 或阴影二选一（不要同时）；标题 16–18px，摘要 14px ≤2 行截断。
**要诀**：同页卡片同构（封面比例、内边距、层级完全一致）；hover 反馈 150ms ease。

## 表单 Form

> 完整规则（标签对齐决策、字段定宽、校验时机、错误文案模板、中文特有字段、布局梯度、可访问性清单）→ **`form-table.md` §1–§11**。此处只给构型与速查。

**构型谱系**：单列顶对齐（移动端/字段少，默认）｜单列右对齐标签（桌面 B 端，紧凑）｜左对齐标签（需慢填的合规表单）｜分步表单（3–5 步）｜卡片分组（>2 屏）｜抽屉编辑（每条目 >8 字段）。
**关键参数**：输入框高 32/40（Ant 默认/大）；内边距 4×11px；圆角 6px；标签 14px、框上 8px（顶对齐）；字段间距 24px；帮助/错误 12–13px 在框下 4–8px；按钮组与输入框**左对齐**。
**要诀**：一个区域内禁多列；能单列不双列；必填只标少数派并解释；校验在失焦与提交，不在键入；错误文案写「哪里错+怎么改」，≤30 字；输入框按内容长度定宽（手机号 160px、身份证 240px，不要全等宽）。
**常见错误**：占位符当标签｜一进来就全红｜提交失败清空表单｜6 位验证码拆 6 个框｜主按钮居右不对齐｜所有框等宽。

## 数据表格 Data Table

> 完整规则（行高计算、列对齐、列宽、固定列、批量操作、空态、可访问性）→ **`form-table.md` §12–§15**。

**构型谱系**：基础表（表头+行+分页）｜查询表格（顶部筛选区 3–4 字段）｜带批量操作（选中后批量条替换工具栏）｜树形表（层级展开）｜可编辑表（每行 2–5 字段）｜卡片化（移动端降级，每行转一张卡）。
**关键参数**：行高 39/47/55px（Ant 三档）或 24/32/40/48/64（Carbon 五档）；**表头、工具栏、批量条、分页四处与行高同高**；表头浅灰底、14px、字重 600；选择列 32px；操作列 80–160px 右固定；默认每页 20 条。
**要诀**：文本左、数字右（+ `tabular-nums`）、操作右固定；列宽按内容分配，关键列不截断；空值统一「—」；区分"无数据"（给新建）与"无结果"（给清除筛选）；筛选变化重置页码；序号用全局公式。
**常见错误**：全列居中｜数字用比例字体｜表头黑底 12px 大写｜行线与斑马纹同用｜空值留白｜每页从 1 编号｜固定列无边界提示。

## 移动端底部导航 Tab Bar

**关键参数**：高度 56–64px + 安全区内嵌；3–5 项，图标 24px + 10–11px 标签；当前项用强调色，其余灰；点击目标 ≥44×44px。
**要诀**：第 5 位常放"我的/更多"；中央凸起 FAB 按钮只用于核心创建动作。

---

## 落地页版式骨架（整页组装）

标准顺序（SaaS，可裁剪）：导航(A) → Hero(A/B) → 社会证明 logo 墙 → Features(3 列) → 用法演示/截图 → 定价(3 档) → 常见问题(手风琴) → CTA(通栏) → Footer(4 列)。
**节奏规则**：相邻区块交替浅底/极浅底或加 1px 分隔；每 2–3 个"内容密"区块后插一个"呼吸"区块（大留白引言/大图）；区块间垂直节奏 96/128/160 递进。

---

## 反模式速查（任何元素通用）

纯灰 #808080 大面积使用｜字号不用阶梯｜间距非 4/8 倍数｜同页两种圆角语言｜标题靠彩色而不是字号字重分层｜动效无反馈/引导/个性用途｜一行放不下还想塞｜对比度 <4.5:1 的正文。
