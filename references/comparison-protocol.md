# 比较协议 · Comparison Protocol


> 打分前的数值争议（行高、对比度、触控尺寸、时长）先查 `numeric-truth.md` §1；受众锚点见 `user-modeling.md` §4。
> 快照 2026-11-19 ｜ 品味层 ②（v52）｜ 上游：`taste-criteria.md`（六维判据、五轴锚点）；下游：`before-after.md`（改稿对照）
> 一句话立场：比较不是找「哪个对」，是找「在什么约束下哪个更好，代价是什么」。
> 检索词：比较 · 三案 · 保守案 · 主流案 · 进取案 · 并置 · 五轴 · 盲评 · 裁决 · 代价 · 改选条件 · 大众审美锚 · 基线 · 反模式

---

## 0. 立场：比较是取舍，不是判对错

**比较不是找「哪个对」，是找「在什么约束下哪个更好，代价是什么」。**

三条推论：

1. **没有代价的裁决是假的**：说「选 B，因为更好看」时，没说 B 牺牲了什么（信息量、工时、风险），等于没裁决。
2. **没有并置的比较是回忆**：凭印象说「A 比 B 好」，比的是记忆里最鲜明的版本，不是画面；必须两案同屏。
3. **没有改选条件的裁决不可复评**：写不出「什么情况下改选 B」，说明裁决依赖的是偏好而不是证据。

本文件只管「方案之间」；「改稿前后」归 `before-after.md`（见该文件末「附 · 复用这 20 组的方法」）。两者都用 `taste-criteria.md` §8 的五轴，不许另立标准。

---

## 1. 三案：保守 / 主流 / 进取

任何比较至少两案并置，标准配置是三案。三案不是「三个风格」，是三种风险姿态：

| 案 | 定义 | 改动幅度 | 什么时候用它 | 最大风险 |
|---|---|---|---|---|
| **保守案** | 沿用当前版本或品类主流范式，只做工艺修正（对齐、间距、对比度），不改结构 | ≤20% | 现状可用、时间紧、合规敏感 | 容易被记成「没做设计」 |
| **主流案** | 当下同类产品的最优实践（样本见 §5） | 30%–60% | 大多数商业项目；评审最容易通过 | 与竞品同质，记忆点低 |
| **进取案** | 挑战一个具名默认假设，允许引入一个新机制 | ≥60% | 品牌重塑、发布页、需要被记住的场合 | 学习成本与转化风险 |

五条规则，缺一条则比较作废：

1. **至少两案并置**：只有一案是陈述，不是比较；只有一案时，先补一个「什么都不改」的保守案。
2. **保守案必选**：它是对照组。没有它，就无法说清「改的价值」，也无法在评审里回答「为什么不保持现状」。
3. **进取案必须写出被挑战的假设**：格式「如果……就……」，例：「如果首屏不需要 logo，就先给产品图」。写不出假设的「大胆方案」只是装饰。
4. **禁止折中案冒充第三案**：把 A 与 B 各取一半，不是新方案，是没做裁决；折中只能作为裁决后的微调。
5. **成本必须写进表**：工时、资产（要不要重拍/重画）、维护（多一套组件）三列至少写一列；不写成本，「最好看」永远赢。

三案命名禁用「方案 1/2/3」：名字要带姿态（保守/主流/进取），否则评审时没人记得住差异。

## 2. 五轴打分：并排、带证据

锚点直接引用 `taste-criteria.md` §8（0–3 分，分数越高越好），本文件不另立锚点，只规定怎么填。

| 轴（0–3） | 保守案 | 主流案 | 进取案 | 每轴一句证据（指到画面位置） |
|---|---|---|---|---|
| 层级清晰 | | | | |
| 节奏 | | | | |
| 一致性 | | | | |
| 记忆点 | | | | |
| 风险 | | | | |
| **合计 /15** | | | | |

六条填写规则：

1. **先独立、后合议**：每位评审先各自填完再讨论（流程见 §4）；当场商量着打分 = 互相锚定。
2. **每轴必须有证据**：证据列写「首屏两个 CTA 同权重」「间距用了 12/14/18/20 四种」，不写「一般」「还行」。
3. **不许半分**：半分通常意味着证据没找齐；回去看画面，不要取中。
4. **0 分即否决**：任一轴 0 分，该案不能中标，除非写明「破的是哪条底线、由谁批准」。
5. **最高分不等于必选**：若最高分案的代价不可接受（如进取案需要重拍全部素材），选次高分并写明改选条件。
6. **同分看代价**：两案同分时，回到 §1 的成本列与本案的 W 列，不许临时加第六个维度。

分数只在同一批比较里有效：跨项目不可比，不同品类的 12 分不是同一件事。

## 3. 强制裁决模板

每次裁决必须写满四个空，缺一个即视为未裁决：

```
选【A】；代价【W】；证据【E】；什么条件下改选【B】。
```

- **A**：案名（保守/主流/进取），不是「方案 2」。
- **W**：具体代价——删掉了什么、多花多少、牺牲了哪条轴；写「没有代价」视为没想清楚。
- **E**：五轴里的 1–3 条 + 可指认的画面证据，不是「综合更好」。
- **B**：具名条件（「如果首屏必须承载 ≥3 条价值主张」），不是「如果领导更喜欢」。

### 例 1：SaaS 落地页首屏（1440×900）

| 案 | 做法 | 改动 | 最大代价 |
|---|---|---|---|
| 保守 | 居中堆叠：标题 + 副标 + 双 CTA + 三张卡片 | ≤20% | 记忆点低，与同类无差别 |
| 主流 | 左文右图：左侧 5 栏文案 + 单 CTA，右侧 7 栏产品图 | 40% | 首屏只讲一条主张，且需要一张能扛 60% 画幅的图 |
| 进取 | 满版单图 + 角落一行标题，首屏不放 CTA | ≥60% | 无 CTA 首屏，转化路径依赖滚动 |

| 轴 | 保守 | 主流 | 进取 | 证据 |
|---|---|---|---|---|
| 层级清晰 | 2 | 3 | 3 | 主流/进取都有唯一入口；保守两个 CTA 同权重互抢 |
| 节奏 | 2 | 3 | 3 | 主流只用 24/48 两档；保守用了 6 种间距 |
| 一致性 | 3 | 3 | 2 | 进取放弃卡片语言，与第二屏断裂 |
| 记忆点 | 1 | 2 | 3 | 进取的满版图一年后还记得；主流只记得「干净」 |
| 风险 | 3 | 2 | 1 | 进取在 B2B 场景缺转化证据 |
| 合计 | 11 | 13 | 12 | |

> 选 **主流案（左文右图）**；代价 **W：首屏信息密度降到一条主张，原三卖点必须下移第二屏，且需要一张能扛 60% 画幅的产品图（当前没有）**；证据 **E：层级 3、节奏 3、一致性 3——沿用全站 12 栏与 24 间距，不新增资产规则；进取案记忆点更高但风险 1 分（无 CTA 首屏在 B2B 缺证据）**；什么条件下改选 **保守案：产品图缺失或首屏必须承载 ≥3 条价值主张时；若品牌已有认知、访客多为回访，可改选进取案。**

### 例 2：投资人路演封面（16:9）

| 案 | 做法 | 改动 | 最大代价 |
|---|---|---|---|
| 保守 | 深色块 + 标题/副标/日期/logo 居中 | ≤15% | 和所有模板一样，第一页没有信息 |
| 主流 | 左对齐 56pt 标题 + 右下一行 14pt 说明 + 一条 1px 分隔线 | 30% | 记忆点弱，封面没有图像叙事 |
| 进取 | 满版摄影 + 左下角 24pt 标题，不放 logo | ≥60% | 窄屏/打印裁切风险，logo 缺失 |

| 轴 | 保守 | 主流 | 进取 | 证据 |
|---|---|---|---|---|
| 层级清晰 | 2 | 3 | 3 | 主流标题左对齐形成唯一入口；保守三级居中互抢 |
| 节奏 | 2 | 3 | 2 | 主流沿用全 deck 的 56/24/14 字阶；进取图片裁切不可控 |
| 一致性 | 3 | 3 | 3 | 三案都可用，进取需新增图片规范 |
| 记忆点 | 1 | 2 | 3 | 满版摄影第一页就有情绪，主流只靠字重 |
| 风险 | 3 | 3 | 2 | 进取在 4:3 投影与 A4 打印上会裁字 |
| 合计 | 11 | 14 | 13 | |

> 选 **主流案**；代价 **W：封面没有图像叙事，记忆点低于进取案，靠字重扛；且 56pt 在 4:3 投影下会缩到 30pt 以下，需要第二版排版**；证据 **E：一致性 3（沿用 4 栏与 56/24/14 字阶）、风险 3（投影与 A4 打印都不裁字）**；什么条件下改选 **进取案：会场屏幕为 16:9 且尺寸足够、或这是「情绪先于信息」的消费品牌路演；若必须带 logo 与法务字样，留在主流案，不选进取案。**

两个例子共同的写法：先列成本，再打分，最后把「不选的那个」写成条件。裁决不超过四句（A、W、E、B 各一句），超过说明还在犹豫。

## 4. 盲评流程

盲评的目的只有一个：让「谁做的」不影响「哪个更好」。评审至少 2 位，其中至少 1 位不是方案作者；作者本人回避盲评，只参加合议后的答疑。

1. **匿名化**：去掉品牌名、来源、作者，统一尺寸与背景，编号随机（A/B/C 顺序每轮打乱）；网页固定视口（如 1440×900），演示文稿固定 16:9。
2. **校准**：开评前一起看 1 个锚样本（§5），对齐「3 分长什么样」；不校准，两位评审会把两套标准带进同一张表。
3. **独立打分**：每位评审先各自填五轴 + 写证据，期间不许讨论；讨论会把分歧提前抹平，抹平的不是共识，是信息。
4. **合议**：只讨论分歧 >1 分的轴；每处分歧必须写「我看到的证据是什么」，不许用「感觉」「经验」。
5. **记录**：谁评、什么时候、样本来源与抓取日期、最终分、分歧理由；记录附在项目裁决里，下一轮可复查。

分歧处理：

- 差 1 分：可接受，不强制写理由，但要各自保留证据句。
- 差 ≥2 分：必须写理由；写不出理由的一方改分，或该轴记为「未定」并补看画面。
- 两轮仍 ≥2 分：引入第三位评审，或把该轴拆成两个更具体的子问题再打。

单人时怎么做：先独立打完五轴并存档，**隔 24 小时不看原稿再打一次**；两次差异 >1 分的轴，以第二次为准并写下改分理由（第一次受「刚做完」的沉没成本影响）。单人盲评的上限是「去偏」，不是「客观」，写裁决时要说明是单人复看。

禁止：评审前讨论方案、评审中互相看分数、用「我更懂这个行业」代替证据、把作者本人拉进盲评。

## 5. 大众审美锚：怎么取、怎么用

「大众审美」不是「主流都这么做」，是**当期受众已经见过的合格线**。取法如下：

1. **取样**：同类产品 20 个，同一品类、同一市场、同一时期；来源写清（应用商店榜单、设计画廊、行业目录），记录抓取日期与平台。
2. **标注**：每个样本写「为什么被视为合格」，三选一或并列——结构（信息怎么排）、材质（深度语言是什么）、密度（一屏几个决策点）。禁止只写「好看」。
3. **留反例**：样本里至少放 3 个同期失败或被公开批评的案例；只看成功案例，学到的是幸存者偏差。
4. **季度更换**：每季度换一次；换的时候保留旧样本的结论作为「上一期基线」，用来区分「趋势变了」还是「我们变了」。
5. **写清边界**：锚只回答「受众见过什么」，不回答「什么更好」；把主流当目标，产出会和竞品一样；把主流当基线，才能说「我偏离了多少、为什么」。

**主流 ≠ 正确。** 主流是共识，共识会过期：纯视觉潮流从引爆到过载通常 12–24 个月（`visual-style-taxonomy.md` §1 的估计）。用两年前的锚评今天的稿，评的是怀旧。

常见误用，三种：

- 把锚当答案：样本都用了大圆角，所以我们也用——这是复制，不是比较。
- 把锚当选票：20 个样本里 15 个居中，所以居中更好——数量不是理由，要看它们为什么居中。
- 把锚当上限：怕偏离主流而不敢选进取案——锚是基线，不是天花板。

## 6. 反模式

1. **只比较规范数值不比整体**：对比度 4.6:1 对 4.8:1，评的是合规，不是画面；数值只该做门槛，不该做裁判。
2. **用投票代替理由**：3:2 通过，没人说得清为什么；投票记录的是偏好分布，不是设计判断。
3. **把熟悉当好看**：「像 XX 就对了」——熟悉只降低学习成本，不产生品味；陌生也可能是更好的选择。
4. **把复杂当高级**：层数多、动效多、信息密度高，不等于有深度；复杂度要有信息量支撑。
5. **只比首屏不比状态**：hover、空态、错误态、暗色全没看，等于只比较了海报，没比较产品。
6. **拿旧锚比新案**：用上季度的样本评本季度的稿，结论一定偏向保守。

## 7. 与 `before-after.md` 的分工

| | `comparison-protocol.md`（本文件） | `before-after.md` |
|---|---|---|
| 比较对象 | 同一 brief 的 2–3 个不同方案 | 同一方案的改稿前 / 改稿后 |
| 回答的问题 | 在约束下选哪个，代价是什么 | 改哪一笔，为什么更好 |
| 产出 | 裁决记录（选 A / 代价 W / 证据 E / 改选 B） | 病稿 → 诊断 → 改稿 → 理由 |
| 使用时机 | 动手前（SKILL 第 3–4 步） | 改稿时与复盘（第 5–6 步） |
| 失败形态 | 比了但没裁决 | 改了但说不清为什么 |

两者可以串联：先用本文件选案，再用 `before-after.md` 改稿；`before-after.md` 里「为什么更好」的每一句，都应能被 `taste-criteria.md` §8 的五轴解释。解释不了的「更好」，要么是口味，要么是没改对。
